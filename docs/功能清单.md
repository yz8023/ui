## 4. 推荐接入顺序

如果你把本仓库当作模板使用，推荐按以下顺序组合：

```text
液态玻璃主题
  → 动效系统
  → 玻璃常用组件
  → 底部导航栏
  → 状态反馈组件
  → 主题色配置与切换
  → 主题配置导入导出
  → 应用欢迎引导界面
  → 权限请求组件 / 协议与开源许可页面
  → 应用图标切换 / 桌面图标动态切换
```

如果只想复制单个功能，请进入对应 `素材库/<功能名>/` 目录，按 `实现方案.md`、`环境要求.md` 和 `代码/` 集成。
