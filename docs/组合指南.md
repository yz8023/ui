# 选择与组合指南

把「素材库」的功能点一步步拼进你自己的工程。

## 1. 先想清楚要什么

| 你想要的效果 | 最少需要的功能点 |
|---|---|
| 只换个应用图标 | 应用图标切换（独立） |
| 想要玻璃质感界面 | 液态玻璃主题 |
| 玻璃 App 的完整壳子 | 液态玻璃主题 + 底部导航栏 + 玻璃常用组件 + 动效系统 |
| 给现有 App 加动效 | 动效系统（独立） |
| 给现有 App 加设置页 | 玻璃常用组件（设置行 / 开关 / 分段控件） |

## 2. 最小接入顺序（从根搭起）

### 第一步：拷贝工程

最简单的方式：把 `android/` 整个拷贝成你的新工程，再删掉不需要的页面。

```bash
cp -r android/ my-app/
```

替换包名 / 应用名：

| 位置 | 原值 | 改为 |
|---|---|---|
| `app/build.gradle.kts` | `applicationId` / `namespace` | 你的包名 |
| 各 `.kt` 文件 | package 声明 | 你的包名 |
| `res/values/strings.xml` | `app_name` | 你的应用名 |

> 建议用 Android Studio 的 Refactor → Rename Package 整体重命名，再核对
> `AndroidManifest.xml` 的引用。

### 第二步：单个功能点接入

如果只想加某一个功能，进入对应 `素材库/<功能名>/`：

1. 把 `代码/` 的文件拷进你的工程对应目录，改 package；
2. 按 `环境要求.md` 加依赖；
3. 按 `实现方案.md` 的「详细步骤」接线；
4. 编译验证 `./gradlew :app:assembleDebug`。

## 3. 各功能点的依赖关系

```
液态玻璃主题 ──依赖──► 底部导航栏
   │                   玻璃常用组件
   └─► 动效系统（三者共用）

应用图标切换：完全独立，随时可加
```

一次选择多依赖功能点时，**先装根基（液态玻璃主题 → 动效系统），再装上层**
（底部导航栏 / 玻璃常用组件），避免缺文件编译报错。

## 4. 换肤与定制

| 想改什么 | 改哪里 |
|---|---|
| 整体配色 | `ui/theme/Color.kt` 的 token |
| 圆角 | `ui/theme/Shape.kt` |
| 字号 | `ui/theme/Type.kt` |
| 玻璃透明度 / 折射率 | 设置页滑块（驱动 `AppChrome`） |
| 底栏标签 | `ui/navigation/Screen.kt` 枚举 |
| 新增页面 | `Screen.kt` 加一项 + `AppRoot.kt` 挂 body |

## 5. 质量约定（接入新代码时请遵守）

1. **动效一律取 token**：从 `Motion` 读，禁止写临时 `spring(...)` 魔法数。
2. **卡片一律玻璃材质**：业务卡片用 `GlassCard` / `liquidGlass`。
3. **按压有反馈**：可点交互叠 `pressScale`。
4. **减少动效保障**：所有入场动画的 `enabled` 读 `reducedMotion`。
5. **状态集中持久化**：设置项收敛到 `AppSettingsState`，不要散在页面里。
