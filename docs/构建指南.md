# 构建指南

本仓库同时支持 **debug 调试包** 和 **release 安装包**。

- Debug APK：适合本地体验和快速验证；
- Release APK：适合在 GitHub Release 中分发安装，使用 release buildType 构建并签名。

## 1. 构建 debug APK

```bash
cd android

# local.properties 需指向你的 SDK（见 环境搭建.md）
# 内容：sdk.dir=/path/to/android-sdk

./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

debug 包使用 Android 默认 debug 签名，装到开启「允许未知来源」的设备即可体验。

## 2. 构建 release APK

### 方式 A：GitHub Release 自动构建（推荐）

推送 `v*` tag 会触发：

```text
.github/workflows/release.yml
```

流程会自动：

1. 安装 JDK 17 与 Android SDK；
2. 生成一次性 release keystore；
3. 执行 `:app:assembleRelease`；
4. 创建 GitHub Release；
5. 上传 `app-release.apk`。

示例：

```bash
git tag v2.1.0
git push origin v2.1.0
```

### 方式 B：本地构建 release APK

```bash
cd android

keytool -genkeypair \
  -v \
  -keystore app/release-ci.jks \
  -storepass changeit-release \
  -keypass changeit-release \
  -alias release \
  -keyalg RSA \
  -keysize 2048 \
  -validity 3650 \
  -dname "CN=LiquidUI,O=MonkeyCode,C=CN"

./gradlew :app:assembleRelease \
  --no-daemon \
  --console=plain \
  -PRELEASE_STORE_FILE=app/release-ci.jks \
  -PRELEASE_STORE_PASSWORD=changeit-release \
  -PRELEASE_KEY_ALIAS=release \
  -PRELEASE_KEY_PASSWORD=changeit-release

# 产物：app/build/outputs/apk/release/app-release.apk
```

> 注意：示例里的 keystore 仅适合演示分发。正式上架应用请使用长期保存的正式 keystore，并妥善备份。

## 3. 验证产物

```bash
/opt/android-sdk/build-tools/35.0.0/apksigner verify --print-certs \
  app/build/outputs/apk/release/app-release.apk
```

Debug 包验证：

```bash
/opt/android-sdk/build-tools/35.0.0/apksigner verify --print-certs \
  app/build/outputs/apk/debug/app-debug.apk
# Signer #1 certificate ... CN=Android Debug
```

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| `SDK location not found` | `android/local.properties` 写 `sdk.dir=` 指向你的 SDK |
| 依赖下载超时 / 失败 | 见下方镜像加速 |
| `Could not find ...gradle:8.7.3` | 网络问题；首次需联网，或走镜像 |
| 首次生成 gradlew 失败 | 加 `--network-timeout=120000` 重试 |
| release 安装提示签名问题 | 确认 APK 已签名，并且覆盖安装时签名与旧版本一致 |
| GitHub Release 没生成 | 检查 tag 是否以 `v` 开头，以及 Actions 是否有 `contents: write` 权限 |

## 5. 依赖镜像加速（中国大陆）

在 `android/settings.gradle.kts` 顶部插入阿里云镜像：

```kotlin
pluginManagement {
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/central")
        maven("https://maven.aliyun.com/repository/gradle-plugin")
        google()
        mavenCentral()
        gradlePluginPortal()
    }
}
dependencyResolutionManagement {
    repositories {
        maven("https://maven.aliyun.com/repository/google")
        maven("https://maven.aliyun.com/repository/central")
        google()
        mavenCentral()
    }
}
```

Gradle 发行版加速：`android/gradle/wrapper/gradle-wrapper.properties` 的
`distributionUrl` 可换
`https://mirrors.cloud.tencent.com/gradle/gradle-8.11.1-bin.zip`。

## 6. 本地在线预览（无需编译）

`web-preview/index.html` 是纯静态交互预览：

```bash
cd web-preview
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
