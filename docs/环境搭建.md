# 环境搭建

本素材库的代码是 Android Jetpack Compose 项目，需要以下环境才能编译运行。

## 1. 安装 JDK（17+）

```bash
# Ubuntu / Debian
sudo apt-get update
sudo apt-get install -y openjdk-17-jdk
```

验证：

```bash
java -version
# 输出 17.x 即可
```

## 2. 安装 Android SDK

需要三个组件：

| 组件 | 版本 | 说明 |
|---|---|---|
| Platform | android-36 | backdrop 玻璃库强制要求 |
| Build Tools | 35.0.0 | 编译工具链 |
| Platform Tools | 最新 | adb 等调试工具 |

用命令行工具安装（也可以直接用 Android Studio 的 SDK Manager）：

```bash
# 下载命令行工具后：
sdkmanager "platforms;android-36" "build-tools;35.0.0" "platform-tools"
```

在工程里创建 `android/local.properties` 指向你的 SDK：

```properties
sdk.dir=/你的/android-sdk/路径
```

## 3. Gradle

工程自带 wrapper（`android/gradlew`），**不需要**单独安装 Gradle。
首次构建会联网下载依赖，大陆网络慢的话参考 `构建指南.md` 的镜像加速。

## 4. 推荐方式：Android Studio

以上全部可以跳过——直接用 Android Studio 打开 `android/` 目录：

1. `File → Open` 选择 `android/` 文件夹；
2. AS 会自动识别 wrapper、SDK 路径并同步依赖；
3. 点绿色运行按钮即可装到模拟器 / 真机。

## 5. 环境验证

```bash
cd android
./gradlew :app:assembleDebug
```

出现 `BUILD SUCCESSFUL` 即环境就绪，产物在
`app/build/outputs/apk/debug/app-debug.apk`。
