# F14 O神主题提示词（给自己的项目加 OShin 同款整套切换）

```
按模板仓库 yz8023/ui 的 F14 给我的 Compose 项目加一套"O神（OShin/Miuix）"视觉风格，
要求像模板示例那样：在风格切换里选它，颜色、卡片、分组标题、翻页壳层、悬浮底栏一起变，
不是只换一个主色。先读该仓库 AGENTS.md、docs/功能逐项手册.md 的 F14 节和
素材库/O神主题与布局/实现方案.md，先回开工表等我确认。

要点（与模板实现逐项对齐）：
1. 新增一个独立风格档（模板叫 VisualMode.OShin），不要去改现有玻璃/普通/MD3 的行为；
   持久化沿用现有的风格状态字段，不要新造第二个状态来源。
2. 四层一起切，缺一层算未完成：
   - 颜色：浅灰页底 #F7F7F7/深色 #000、卡片 #FFFFFF/#242424、主蓝 #3482FF（深色 #0091FF）；
   - 形状排版：卡片圆角 16dp（不是原来的大圆角）、页面大标题、分组标题改灰色小标题；
   - 卡片材质：该模式下所有卡片落成实色无阴影，不要玻璃折射/高光；
   - 壳层布局：内容改左右翻页（HorizontalPager），底栏改悬浮胶囊
     （左右各留 40dp、底 16dp、高约 64dp，图标 24dp+标签 11sp，选中系统蓝），
     底栏点击滚页、翻页定格后回写选中态，翻页时相邻页加偏移模糊（上限 16dp，API 31+）。
3. 组件名字与文件按模板原样（OShinTheme.kt / OShinComponents.kt 等），只改 package 与 R；
   不要引入 Miuix 库，不要复制 OShin 的 AGPL 源码——只按模板这套已独立实现的 token 落地，
   并在关于页/文档保留"设计参考：suqi8/OShin"的署名。

验收（逐项汇报）：切换瞬间四层全变且不重启；翻页与底栏双向联动；列表底部不被底栏遮挡
（预留 ≥108dp）；深浅色各看一遍；切回原风格完全还原；杀进程后仍保持该风格。
与模板的差异单列一节（例如底栏滚动隐藏没做、底栏模糊是高不透明近似），没有写"无"。
```
