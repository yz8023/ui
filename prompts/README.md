# 提示词使用说明

把模板交给别人或 AI 时，**仓库地址 + 对应提示词 + 功能编号**三件套一起发，只发仓库地址等于没发。

| 提示词 | 用在什么时候 |
|---|---|
| `00-通用开工.md` | 任何任务的第一条消息（先体检、先出开工表） |
| `01-换图标-含Java版.md` | F01 换图标，Compose 与 Java/View 宿主都可用（内附 Java 完整等价代码） |
| `02-液态玻璃-Compose项目.md` | F03（可连带 F08/F09/F10），宿主已是 Compose 时 |
| `03-液态玻璃-View项目先看这个.md` | 宿主是 Java/View 还想要玻璃时，**先发这条确认路线，确认前禁止写代码** |
| `04-玻璃组件与底栏组合.md` | F08+F09+F10 整套玻璃壳子（Compose 宿主） |
| `06-O神主题.md` | F14 一键切 OShin（Miuix）同款主题+布局（Compose 宿主） |
| `05-单功能通用模板.md` | 其余功能（F04–F07、F11–F13）填空套用 |

用法：把文件全文复制为任务的第一条消息，把文中的 `【】` 替换成你的实际情况。
对方（人或 AI）没有按提示词回「开工表」就开始写代码时，立即打断——这是过去所有返工的共同起点。
