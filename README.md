# Android 素材库 · 选择式功能开发

> 面向普通人的 **Android 功能素材库**：不要求从零写代码。想给你的 App 加什么
> 功能，就打开对应的中文功能文件夹，照着「实现方案」抄代码、按步骤组装，
> 一个个功能选着搭，拼出属于自己的应用。

## 这是什么

本仓库把常用的 Android 开发能力拆成一个个独立的**功能点**。每个功能点是一个
**中文命名的文件夹**，里面包含四样东西：

| 内容 | 说明 |
|---|---|
| `实现方案.md` | 怎么做的原理、步骤、常见问题（给普通人看的） |
| `代码/` | 可直接复制使用的完整代码 |
| `参考来源.md` | 参考了哪些开源项目 / 官方文档（溯源） |
| `环境要求.md` | 依赖、SDK 版本、需要改哪些文件 |

## 怎么使用（三步走）

1. **挑功能**：看下面的「功能索引」，找到你想要的功能点。
2. **抄代码**：进入对应文件夹，把 `代码/` 里的文件复制进你的工程，
   改包名即可。
3. **照步骤组装**：按 `实现方案.md` 的步骤接线，参考 `环境要求.md` 装好依赖。

想先看整体效果？直接安装 `android/` 示例应用（所有素材的组合演示），
在真机上体验后再选功能。

## 功能点之间的关系

```
应用欢迎引导界面（独立，任何工程可直接加）

主题色配置与切换（独立，与 Material 3 主题系统集成）
  ├─ 主题配置导入导出（依赖设置状态类）
  └─ 桌面图标动态切换（依赖 activity-alias，集成在主题设置页中）

液态玻璃主题（根基：玻璃 + 换肤）
  ├─ 底部导航栏（依赖玻璃主题 + 动效系统）
  ├─ 玻璃常用组件（依赖玻璃主题 + 动效系统）
  ├─ 状态反馈组件（依赖玻璃组件 + 动效系统，可降级）
  └─ 动效系统（可独立使用，也随玻璃主题一起用）

权限请求组件 / 协议与开源许可页面（应用基础能力，可独立加）
应用图标切换（独立，任何工程可直接加）
```

想搭一个"玻璃风格"的应用，最少只需要「液态玻璃主题」一个素材；
要完整壳子，就选「液态玻璃主题 + 底部导航栏 + 玻璃常用组件 + 动效系统」。

参考项目 CYQawa/YunX 额外提供了「主题色配置与切换」和「桌面图标动态切换」两个独立素材，
可单独集成到任何 Material 3 项目中。

## 示例应用

`android/` 是一个完整的、可编译的示例工程，演示了所有素材如何组合：

- 首次启动：引导页（品牌介绍 + 功能列表 + 免费声明 + 免责说明 + 开源入口）
- 设置页：三态视觉风格（玻璃 / 普通 / MD3）、7 套配色、自定义调色盘
- 设置页「主题与外观」：跟随系统 / 浅色 / 深色模式，动态色彩 / 默认蓝色 / 自定义颜色
- 设置页「主题配置」：导出当前主题 JSON / 从剪贴板导入恢复
- 设置页「桌面图标」：经典图标 / 新图标即时切换
- 设置页「应用图标」区：冰蓝 / 星夜 / 珊瑚三套图标即时切换
- 首次启动欢迎引导页，设置页可重新查看
- 帮助与合规：开源许可、隐私说明、项目主页入口
- 液态玻璃底栏 + 四页面导航 + 全应用弹簧动效
- 预览截图在 `preview/`，纯静态交互预览在 `web-preview/index.html`

## 环境与构建

| 项 | 要求 |
|---|---|
| JDK | 17+ |
| Android SDK | platform-36、build-tools 35.0.0 |
| Gradle | 8.11.1（工程自带 wrapper） |
| Kotlin / AGP | 2.3.10 / 8.7.3 |

```bash
cd android
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

详细见 `docs/构建指南.md`。环境装不来的话，直接把 `android/` 用 Android Studio
打开即可（AS 会自动识别 wrapper 与 SDK）。
