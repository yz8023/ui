# F16 · 面包屑 — 实现方案

> 分类：03 导航　｜　难度：★☆☆　｜　主题：导航
>
> 一句话：空间不足时折叠中间层级（首层 + … + 末层），hover 省略号弹出被折叠的部分；分隔符用伪元素，不占 DOM。

## 一、效果（用户看到什么）

空间不足时折叠中间层级（首层 + … + 末层），hover 省略号弹出被折叠的部分；分隔符用伪元素，不占 DOM。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

空间不足时折叠中间层级（首层 + … + 末层），hover 省略号弹出被折叠的部分；分隔符用伪元素，不占 DOM。

关键点：

- 用容器宽度与每段宽度累加判断是否折叠，ResizeObserver 监听变化。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 最多显示 3 段 · 折叠后 首/…/末 · 分隔符 10px 透明度 40% | 改动这里就能整体换手感 |

## 四、详细步骤

1. 用容器宽度与每段宽度累加判断是否折叠，ResizeObserver 监听变化。

## 五、验收判据（逐条可测）

- [ ] 窄容器下自动折叠
- [ ] 展开列表可点
- [ ] 当前页不可点且颜色更深。

## 六、红线（违反即返工）

- ✕ 不许在移动端横向滚动面包屑（会顶破布局）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 省略号点了没反应 | 省略号只是文本 | 省略号做成按钮 + 浮层 |

## 八、可直接复制的提示词

```text
做自适应面包屑：层级为 首页 / 素材库 / 组件 / 表单 / 输入框。
【折叠】容器不够宽时保留首层与末层，中间折叠成「…」，点击省略号弹出被折叠的层级列表。
【样式】分隔符用 ::after（10px、透明度 40%），当前页加粗且不可点，其余 hover 变亮。
【自检】320px 宽时折叠正确；省略号浮层可点；当前页无 hover 反馈。
```
