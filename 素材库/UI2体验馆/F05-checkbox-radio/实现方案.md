# F05 · 复选与单选 — 实现方案

> 分类：01 基础组件　｜　难度：★☆☆　｜　主题：选择
>
> 一句话：勾选用 SVG path 的 stroke-dashoffset 画出来（180ms），单选用内点缩放；点击热区 44px，视觉只有 20px。

## 一、效果（用户看到什么）

勾选用 SVG path 的 stroke-dashoffset 画出来（180ms），单选用内点缩放；点击热区 44px，视觉只有 20px。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

勾选用 SVG path 的 stroke-dashoffset 画出来（180ms），单选用内点缩放；点击热区 44px，视觉只有 20px。

关键点：

- 用 label 包住 input，视觉层用 span，隐藏原生 input 但保留可访问性。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 视觉 20 · 热区 44 · 勾线 180ms · 单选内点 6→8px | 改动这里就能整体换手感 |

1. 用 label 包住 input，视觉层用 span，隐藏原生 input 但保留可访问性。

## 五、验收判据（逐条可测）

- [ ] 勾选动画期间快速连点不破形
- [ ] 点击文字也能选中
- [ ] 单选框同组互斥。

## 六、红线（违反即返工）

- ✕ 不许把热区做成只有 20px（违反 44px 最小触控面积）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 文字点不中 | label 没包住 | 用 <label> 包 input + 文本 |

## 八、可直接复制的提示词

```text
做复选框与单选框（各 3 个），视觉 20px、热区 44px。
【勾选动画】用 SVG path 的 stroke-dasharray/stroke-dashoffset 在 180ms 内"画出"对勾；
【单选】外圈 20px 描边 + 内点从 6px 弹到 8px（弹簧曲线）；
【可访问】原生 input 保留（可 Tab、可用空格），视觉层用 span[aria-hidden]；
【自检】点击整行都能切换；单选框同组互斥；连续快速点击 10 次状态与视觉不脱节。
```
