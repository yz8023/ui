# F31 · 加载按钮 — 实现方案

> 分类：05 反馈　｜　难度：★☆☆　｜　主题：反馈
>
> 一句话：按钮进入 loading 时宽度锁定（避免塌陷），文字换成三点脉冲 + 进度描边；完成后打勾回弹 1.06 再复原。

## 一、效果（用户看到什么）

按钮进入 loading 时宽度锁定（避免塌陷），文字换成三点脉冲 + 进度描边；完成后打勾回弹 1.06 再复原。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

按钮进入 loading 时宽度锁定（避免塌陷），文字换成三点脉冲 + 进度描边；完成后打勾回弹 1.06 再复原。

关键点：

- 点击立即 disabled + 记录当前 offsetWidth 作为 min-width。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 宽度锁定用 min-width · 三点脉冲 1.1s · 成功回弹 220ms scale 1.06 | 改动这里就能整体换手感 |

## 四、详细步骤

1. 点击立即 disabled + 记录当前 offsetWidth 作为 min-width。

## 五、验收判据（逐条可测）

- [ ] loading 期间宽度不变
- [ ] 连点只触发一次
- [ ] 成功后按钮可再次点击。

## 六、红线（违反即返工）

- ✕ 不许 loading 时还能重复提交。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 按钮宽度跳一下 | 只把文字换成小圆点 | 先锁 min-width 再改内容 |

## 八、可直接复制的提示词

```text
做加载按钮：三态 idle → loading → success → idle。
【要求】进入 loading 前记录按钮 offsetWidth 并设为 min-width（宽度不跳）；loading 时文字替换为三点脉冲动画；
1.4s 后变 success（打勾 + scale 1.06 回弹 220ms），再过 900ms 回到 idle。
【约束】loading 期间 disabled 且 cursor 为 progress；重复点击只触发一次。
【自检】三态切换宽度差 0；连点 5 次只发一次请求；成功动画只播一次。
```
