数字滚动 + 迷你趋势线：数值用 rAF 从 0 滚到目标（easeOutExpo），趋势线同步描边生长，变化率用颜色与箭头双重编码（不只靠颜色）。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

数字滚动 + 迷你趋势线：数值用 rAF 从 0 滚到目标（easeOutExpo），趋势线同步描边生长，变化率用颜色与箭头双重编码（不只靠颜色）。

关键点：

- 用 Intl.NumberFormat 做千分位；rAF 里只更新 textContent，不触发重排。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 滚动 1.1s easeOutExpo · 趋势线 24px 高 · 变化率 ±% 带箭头 | 改动这里就能整体换手感 |

## 四、详细步骤

1. 用 Intl.NumberFormat 做千分位；rAF 里只更新 textContent，不触发重排。

## 五、验收判据（逐条可测）

- [ ] 数字停在精确值（不是近似）
- [ ] 千分位正确
- [ ] 箭头方向与正负一致。

## 六、红线（违反即返工）

- ✕ 不许只靠颜色表达涨跌（色盲不可读）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 数字比 1 万显示成 10000.00 | toFixed 没配千分位 | Intl.NumberFormat("zh-CN") |

## 八、可直接复制的提示词

```text
做数据卡：标题「本月活跃」+ 数字 12,480 + 变化率 +8.2%（绿）+ 迷你趋势线。
【数字】rAF 1.1s easeOutExpo 从 0 滚到 12480，千分位用 Intl.NumberFormat('zh-CN')；
【趋势线】24px 高的 SVG 折线，pathLength 描边生长 1s，末端一个脉冲点。
【变化率】+8.2% 用绿色 + ↑ 箭头（箭头与颜色双重编码）；负值时红色 + ↓。
【自检】最终值精确 12,480；千分位正确；箭头与符号一致；卡内无溢出。
```
