## 二、实现原理

刘海 / 底部指示条模拟：内容必须避开 notch 与 home indicator，用 env(safe-area-inset-*) 与 padding 折叠；错误示范用红色标出被遮挡区域。

关键点：

- 用 padding: env(safe-area-inset-top) 而不是固定像素；模拟时用 CSS 变量替代。

## 五、验收判据（逐条可测）

- [ ] 切换「安全区」开关时，标题不被刘海遮挡、底栏不被指示条压住
- [ ] 错误示范必须明显可见。

## 六、红线（违反即返工）

- ✕ 不许把关键操作放在底部 20px 内（会被系统手势抢走）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 内容被刘海咬掉 | 全屏 100vh 无内边距 | 给容器加 safe-area padding |

## 八、可直接复制的提示词

```text
做安全区演示：一个手机外框（带刘海与底部指示条），内部顶部标题 + 内容 + 底部操作条。
【开关】「安全区」开：容器顶部 padding 28、底部 20，内容完全避开；
关：内容贴边，用红色描出被遮挡区域并显示「被遮挡」标记。
【要求】用 CSS 变量 --sat/--sab 模拟 env(safe-area-inset-*)；外框圆角 28、边框 1px。
【自检】开/关两态遮挡区域差异肉眼可见；底部按钮不被指示条压住；切换无抖动。
```
