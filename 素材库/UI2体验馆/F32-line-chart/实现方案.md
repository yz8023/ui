## 一、效果（用户看到什么）

SVG 折线 + 面积渐变 + 描边生长：path 用 pathLength=1 把 dashoffset 从 1 动画到 0（1.2s），面积同时淡入；悬停时用二分查找最近的点，垂直参考线跟随。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

SVG 折线 + 面积渐变 + 描边生长：path 用 pathLength=1 把 dashoffset 从 1 动画到 0（1.2s），面积同时淡入；悬停时用二分查找最近的点，垂直参考线跟随。

关键点：

- 用 Catmull-Rom 转贝塞尔把折线变平滑，控制点系数 1/6。
- 面积 path 由折线闭合到底部得到，单独一层渐变填充。

## 四、详细步骤

1. 用 Catmull-Rom 转贝塞尔把折线变平滑，控制点系数 1/6。
2. 面积 path 由折线闭合到底部得到，单独一层渐变填充。

## 五、验收判据（逐条可测）

- [ ] 描边一次画完
- [ ] 悬停参考线吸附到最近点
- [ ] 离散点数量变化时曲线仍平滑。

## 六、红线（违反即返工）

- ✕ 不许为了"平滑"把数据点削掉（曲线必须穿过真实点）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 曲线不经过数据点 | 用了简单二次贝塞尔近似 | Catmull-Rom 转三次贝塞尔 |

## 八、可直接复制的提示词

```text
做折线图（7 个数据点）。
【绘制】SVG viewBox 0 0 260 110；用 Catmull-Rom 转三次贝塞尔让折线平滑且必须穿过每个真实点；
描边 2px、圆头；下方面积用同一条路径闭合到底部，填充线性渐变（0.22 → 0）。
【动效】pathLength=1，stroke-dashoffset 1→0，1.2s ease-out；面积 opacity 0→1 延迟 0.3s。
【交互】pointermove 时按 x 找最近点，画垂直虚线 + 高亮点 + 数值气泡；离开时淡出。
【自检】曲线穿过 7 个点；描边一次流畅画完；气泡吸附最近点不抖动。
```
