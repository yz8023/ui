# F36 · 数据表格 — 实现方案

> 分类：06 数据展示　｜　难度：★★☆　｜　主题：数据
>
> 一句话：表头吸顶 + 行错峰入场 + 排序指示器；行高 34、粘性表头带描边阴影（滚动时才出现）。

## 一、效果（用户看到什么）

表头吸顶 + 行错峰入场 + 排序指示器；行高 34、粘性表头带描边阴影（滚动时才出现）。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

表头吸顶 + 行错峰入场 + 排序指示器；行高 34、粘性表头带描边阴影（滚动时才出现）。

关键点：

- 用 position: sticky 的表头 + 容器滚动；滚动时给表头加 class 切阴影。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 行高 34 · 入场 240ms 错峰 28ms · 表头 shadow 在 scrollTop>2 时出现 | 改动这里就能整体换手感 |

## 四、详细步骤

1. 用 position: sticky 的表头 + 容器滚动；滚动时给表头加 class 切阴影。

## 五、验收判据（逐条可测）

- [ ] 表头始终可见
- [ ] 排序箭头切换正确
- [ ] 行入场不导致表头抖动。

## 六、红线（违反即返工）

- ✕ 不许用 <table> 的 border-collapse 配合 sticky（部分浏览器 sticky 失效）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 表头随页面滚走 | sticky 的父级 overflow: auto 但表头不在滚动容器内 | 表头放在滚动容器里并加背景色 |

## 八、可直接复制的提示词

```text
做数据表格：5 列（名称 / 分类 / 状态 / 更新 / 操作），6 行。
【样式】行高 34、表头 10.5px 大写字距、斑马纹极弱（3%）、状态用色点 + 文字；
【行为】表头 position:sticky top:0 且不透明；容器 scrollTop>2 时给表头加深阴影；
点击「更新」列排序，箭头升/降切换；行入场 opacity+translateY(6px)，逐行 28ms 延迟。
【自检】表头滚动时始终遮住内容；排序结果正确；行入场不引起横向抖动。
```
