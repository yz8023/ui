## 二、实现原理

纯 CSS 头像：无图时用姓名首字 + 由名字哈希出的双色渐变；状态点用 2px 描边把头像"挖"出来；徽标数字超过 99 显示 99+，宽度随位数自适应。

关键点：

- hash 用字符码累加取模，保证同一个名字恒色（服务端渲染也一致）。
- 徽标用 min-width + padding，避免两位数字撑成椭圆。

## 四、详细步骤

1. hash 用字符码累加取模，保证同一个名字恒色（服务端渲染也一致）。
2. 徽标用 min-width + padding，避免两位数字撑成椭圆。

## 五、验收判据（逐条可测）

- [ ] 同名同色、不同名不同色
- [ ] 没有图片时不出现破图
- [ ] 徽标在两位数时不压住头像主体。

## 六、红线（违反即返工）

- ✕ 不许给头像塞随机色（刷新一次变一个颜色）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 破图 | img 无 onerror 兜底 | 无 src 时直接用首字方案 |

## 八、可直接复制的提示词

```text
做头像 + 状态点 + 数量徽标。
【头像】无图时显示姓名首字；背景色由名字哈希出两个色相做 135° 渐变，保证同名恒色。
【尺寸】28 / 36 / 48 / 64 四档，字号按尺寸线性缩放。
【状态】右下角 10px 圆点，2px 深色描边把头像"挖"出来；支持 online/busy/offline 三色。
【徽标】18px 高，min-width 18 + padding 4，超过 99 显示 99+；用 translate 挂在右上角，不遮挡人脸。
【自检】同名同色；两位数徽标不变形；无图不破图。
```
