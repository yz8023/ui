# F01 · 按钮 — 实现方案

> 分类：01 基础组件　｜　难度：★☆☆　｜　主题：交互基础
>
> 一句话：三档层级（primary / secondary / ghost）+ 图标按钮；按下用 0.955 缩放 + 120ms 弹簧回弹代替水波纹，加载态在原地把文字换成三点脉冲，尺寸一像素不动。

## 一、效果（用户看到什么）

三档层级（primary / secondary / ghost）+ 图标按钮；按下用 0.955 缩放 + 120ms 弹簧回弹代替水波纹，加载态在原地把文字换成三点脉冲，尺寸一像素不动。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

三档层级（primary / secondary / ghost）+ 图标按钮；按下用 0.955 缩放 + 120ms 弹簧回弹代替水波纹，加载态在原地把文字换成三点脉冲，尺寸一像素不动。

关键点：

- 先把三档层级做成 variant，用一个 class 切换，不要复制三份结构。
- 按下反馈用 :active 的 transform（GPU 合成层，不触发重排）。
- 加载态保留原宽度：用等宽占位替换文字，而不是隐藏整个按钮。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 高度 40 / 32（sm）/ 44（lg）· 圆角 12 · 按压 scale .955 · 回弹 160ms cubic-bezier(.2,.9,.3,1.15) | 改动这里就能整体换手感 |

## 四、详细步骤

1. 先把三档层级做成 variant，用一个 class 切换，不要复制三份结构。
2. 按下反馈用 :active 的 transform（GPU 合成层，不触发重排）。
3. 加载态保留原宽度：用等宽占位替换文字，而不是隐藏整个按钮。

## 五、验收判据（逐条可测）

- [ ] 按下必须立刻有缩放反馈（<16ms）
- [ ] 加载态宽度不跳
- [ ] 禁用态不可聚焦、aria-disabled=true。

## 六、红线（违反即返工）

- ✕ 不许用 box-shadow 做按压（会重绘，低端机掉帧）。
- ✕ 按钮文字禁止硬编码宽度，必须 padding 撑开以适配多语言。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 按住时文字抖动 | 用了 width 过渡 | 改用 padding + transform，不写 width/margin 过渡 |
| 加载后按钮变窄 | 加载态没有占位 | 把文字设成 visibility:hidden 保留占位 |

## 八、可直接复制的提示词

```text
做一个零依赖的按钮组件，三档层级 + 图标按钮 + 加载态。
【结构】<button class="btn btn--primary|secondary|ghost">，可选 data-icon、data-loading。
【规格】高度 40（sm 32 / lg 44），圆角 12，左右 padding 16，字号 13，字重 600。
【交互】按下 scale(.955)，160ms cubic-bezier(.2,.9,.3,1.15) 回弹；悬停只改亮度不改尺寸；
加载态把文字换成三个脉冲点，按钮宽度保持不变；禁用态 aria-disabled="true" 且不可聚焦。
【自检】按键 Tab 能聚焦且焦点环 2px；连续点 10 次不累积位移；加载态宽度与常态一致（截图叠对比）。
```
