# F22 · 响应式栅格 — 实现方案

> 分类：04 布局　｜　难度：★★☆　｜　主题：布局
>
> 一句话：断点标尺可视化：拖动容器宽度，实时显示当前断点（xs/sm/md/lg）与列数；列用 minmax + auto-fit 自适应。

## 一、效果（用户看到什么）

断点标尺可视化：拖动容器宽度，实时显示当前断点（xs/sm/md/lg）与列数；列用 minmax + auto-fit 自适应。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

断点标尺可视化：拖动容器宽度，实时显示当前断点（xs/sm/md/lg）与列数；列用 minmax + auto-fit 自适应。

关键点：

- 用 clamp + auto-fit 减少显式媒体查询，断点只用于排版细节。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 断点 360 / 560 / 760 · 列宽 minmax(64px,1fr) · gap 8 | 改动这里就能整体换手感 |

## 四、详细步骤

1. 用 clamp + auto-fit 减少显式媒体查询，断点只用于排版细节。

## 五、验收判据（逐条可测）

- [ ] 跨断点时列数正确变化
- [ ] 标尺指针跟随
- [ ] 无横向滚动。

## 六、红线（违反即返工）

- ✕ 不许只写 max-width 而没有 min-width 适配（小屏会挤）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 列数算错 | 用 container 宽度算但读了 window | 用 ResizeObserver 读容器 |

## 八、可直接复制的提示词

```text
做响应式栅格演示：一个可拖动宽度的容器（260–100%）+ 内部 8 个格子。
【行为】grid-template-columns: repeat(auto-fit, minmax(64px, 1fr))；容器宽度变化时列数实时变化；
顶部标尺显示当前宽度、断点（<360 xs / <560 sm / <760 md / 其他 lg）与列数。
【自检】拖到任意宽度无横向滚动；列数 = floor((w+gap)/(64+gap))；断点标签实时更新。
```
