# F07 · 表单校验 — 实现方案

> 分类：02 表单输入　｜　难度：★★☆　｜　主题：表单
>
> 一句话：即时校验 + 失焦才报错 + 提交时全量校验：输入中只给正向提示，blur 后才显示错误，提交时把第一个错误滚进视野并聚焦。

## 一、效果（用户看到什么）

即时校验 + 失焦才报错 + 提交时全量校验：输入中只给正向提示，blur 后才显示错误，提交时把第一个错误滚进视野并聚焦。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

即时校验 + 失焦才报错 + 提交时全量校验：输入中只给正向提示，blur 后才显示错误，提交时把第一个错误滚进视野并聚焦。

关键点：

- 把字段规则抽成数组，同一套规则驱动即时提示与提交校验。
- 禁用按钮会让用户不知道为什么不能提交，改用「可点 + 提示第一个错误」。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 校验时机 = blur / submit · 错误文案 1 行 · 提交按钮在无效时 aria-disabled 但可点（点了给提示） | 改动这里就能整体换手感 |

## 四、详细步骤

1. 把字段规则抽成数组，同一套规则驱动即时提示与提交校验。
2. 禁用按钮会让用户不知道为什么不能提交，改用「可点 + 提示第一个错误」。

## 五、验收判据（逐条可测）

- [ ] 输入过程中不弹错
- [ ] 失焦后立即报错
- [ ] 提交无效时焦点跳到第一个错误字段。

## 六、红线（违反即返工）

- ✕ 不许在用户还没输完时就报错。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 一直红着 | input 事件里就校验 | 输入时清错，blur 才校验 |

## 八、可直接复制的提示词

```text
做三步式表单校验（姓名 / 邮箱 / 密码）。
【时机】输入中不报错，只清错；失焦校验该字段；提交时校验全部并把焦点移到第一个错误。
【反馈】错误字段边框变红 + 下方一行文案 + aria-invalid="true" + aria-describedby 关联；
正确时字段尾部出现绿色对勾。
【提交】全部通过后按钮进入 loading → 成功态（对勾 + 文案变化）。
【自检】输入过程中无红色；失焦立刻报错；提交无效时焦点正确；截图对比错误/成功两态。
```
