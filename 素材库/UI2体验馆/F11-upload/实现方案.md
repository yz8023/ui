# F11 · 文件上传 — 实现方案

> 分类：02 表单输入　｜　难度：★★☆　｜　主题：输入
>
> 一句话：拖拽区 + 队列 + 单文件进度条：拖入高亮、逐个上传、失败可重试；上传用分片模拟，进度条只改 transform。

## 一、效果（用户看到什么）

拖拽区 + 队列 + 单文件进度条：拖入高亮、逐个上传、失败可重试；上传用分片模拟，进度条只改 transform。

演示入口：本目录 `index.html`（自包含，双击即可运行）。

## 二、实现原理

拖拽区 + 队列 + 单文件进度条：拖入高亮、逐个上传、失败可重试；上传用分片模拟，进度条只改 transform。

关键点：

- 进度用 CSS 变量 --p 驱动 scaleX，避免每帧改 width 引发重排。

## 三、参数表

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 参数组 | 拖拽高亮 120ms · 进度条用 scaleX · 队列串行（同时 1 个） | 改动这里就能整体换手感 |

## 四、详细步骤

1. 进度用 CSS 变量 --p 驱动 scaleX，避免每帧改 width 引发重排。

## 五、验收判据（逐条可测）

- [ ] 拖入时高亮、离开恢复
- [ ] 队列串行不并发
- [ ] 失败项可单独重试
- [ ] 全部完成后按钮变成功态。

## 六、红线（违反即返工）

- ✕ 不许并发上传全部文件（移动网络会互相抢带宽）。

## 七、失败指纹（改坏了长什么样）

| 现象 | 根因 | 修正 |
| --- | --- | --- |
| 进度条抖动 | 每帧改 width | 改用 transform: scaleX(var(--p)) |

## 八、可直接复制的提示词

```text
做文件上传：可点击 / 可拖拽的区域 + 文件队列 + 单文件进度 + 失败重试。
【区域】虚线边框，拖入时描边变主题色并轻微放大（120ms）。
【队列】串行上传，每项显示文件名、大小、进度条（用 transform: scaleX 驱动，不写 width）；
失败项显示红色与「重试」；全部完成后按钮文字变「✓ 已上传 3 个」。
【自检】拖拽高亮进出正常；进度条 60fps 不抖动；失败重试只重跑该项；无文件时按钮禁用。
```
