# 环境要求

- Android minSdk 26+
- Kotlin 协程（`lifecycle-runtime-ktx` 已传递提供）
- Manifest 添加：`<uses-permission android:name="android.permission.INTERNET" />`
- Compose Activity Result API 用于选择本地图片
- 应用设置状态需保存：壁纸模式、缓存文件路径、原始网络 URL
- 不需要 Coil、Glide 等图片依赖，因此对 APK 体积影响很小
- 系统壁纸模式：不要申请 `READ_MEDIA_IMAGES`（对 WallpaperManager 无效）；仅 Android ≤12 需要 Manifest 声明 `READ_EXTERNAL_STORAGE`（`maxSdkVersion=32`）以读取真实壁纸；Android 13 返回默认壁纸、14+ 系统拒绝直接读取（模板不申请 `MANAGE_EXTERNAL_STORAGE`），此时应提示用户改用本地缓存
