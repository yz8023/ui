# 环境要求

- Android minSdk 26+
- Kotlin 协程（`lifecycle-runtime-ktx` 已传递提供）
- Manifest 添加：`<uses-permission android:name="android.permission.INTERNET" />`
- Compose Activity Result API 用于选择本地图片
- 应用设置状态需保存：壁纸模式、缓存文件路径、原始网络 URL
- 不需要 Coil、Glide 等图片依赖，因此对 APK 体积影响很小
- 系统壁纸模式：不要申请 `READ_MEDIA_IMAGES`（对 WallpaperManager 无效）；Android ≤12 需要 Manifest 声明 `READ_EXTERNAL_STORAGE`（`maxSdkVersion=32`）读真实壁纸；Android 11+ 需要声明 `MANAGE_EXTERNAL_STORAGE`（「所有文件访问」，只能跳系统设置页 `ACTION_MANAGE_APP_ALL_FILES_ACCESS_PERMISSION` 开启，无运行时弹窗），否则 Android 14+ 必然读不到壁纸——这是 pan-x 壁纸能用的前提，缺一不可。注意该权限属高敏感权限，上架应用商店需按其政策评估
