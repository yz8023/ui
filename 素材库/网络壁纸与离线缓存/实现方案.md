# 网络壁纸与离线缓存 · 实现方案

此功能不是把 URL 直接交给图片组件：用户输入 HTTPS 图片链接后，应用会下载、限制大小、验证图片、按最大 4096 像素降采样，再以 WebP 原子写入应用私有目录。界面始终读取本地缓存，所以原链接失效、网络断开或源站删除图片后仍能继续使用。

## 完整流程

1. 设置页输入图片直链，点击“下载并应用”。
2. `WallpaperStore.cacheNetwork` 在 IO 调度器下载，限制 20MB、12 秒连接和 20 秒读取超时。
3. 先读取图片尺寸，拒绝无法解码或像素数异常的内容。
4. 大图按 2 的倍数降采样，避免解码时内存暴涨。
5. 写入临时文件并 `fsync`，最后原子替换正式缓存。
6. 将缓存绝对路径、原始 URL 与当前壁纸模式写入设置状态。
7. App 根节点只解码缓存文件并作为 backdrop 录制层，玻璃卡片对其做真实折射。

本地图片同样复制进私有缓存，而不是长期依赖外部 `content://` 权限。
