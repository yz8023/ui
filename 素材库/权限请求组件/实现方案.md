# 权限请求组件 · 实现方案

## 1. 功能效果

把 Android 运行时权限封装成统一的说明卡：

- 先解释权限用途，再请求；
- 显示「已授权 / 未授权」状态；
- 被拒绝后提供「系统设置」入口；
- 支持通知、媒体、相机、位置、麦克风等权限；
- UI 风格跟随本项目玻璃卡片与 Material 3 主题。

## 2. 实现原理

核心由三部分组成：

1. `PermissionSpec`：描述权限名、标题、说明、拒绝提示；
2. `PermissionRequestCard`：Compose 权限说明卡；
3. `Context.openAppPermissionSettings()`：跳转系统应用设置，处理永久拒绝后的恢复路径。

请求权限使用官方 `ActivityResultContracts.RequestPermission()`，避免手写 `onRequestPermissionsResult`。

## 3. 详细步骤

### 步骤 1：拷贝代码

```text
素材库/权限请求组件/代码/权限请求组件.kt
```

拷贝到你的工程，例如：

```text
app/src/main/java/你的包名/ui/features/PermissionToolkit.kt
```

并修改文件顶部的 `package`。

### 步骤 2：在 Manifest 声明权限

例如通知权限：

```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

相机权限：

```xml
<uses-permission android:name="android.permission.CAMERA" />
```

### 步骤 3：在设置页使用

```kotlin
PermissionRequestCard(
    spec = PermissionSpec(
        permission = Manifest.permission.POST_NOTIFICATIONS,
        title = "通知权限",
        description = "用于发送任务完成、更新检测和重要提醒。"
    )
)
```

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 点授权没有弹窗 | 检查 Manifest 是否声明权限 |
| 用户勾选不再询问 | 引导点击「设置」到系统应用设置页开启 |
| Android 13 以下通知权限异常 | 只在 `Build.VERSION.SDK_INT >= 33` 时展示通知权限请求 |
| 想一次请求多个权限 | 可改用 `ActivityResultContracts.RequestMultiplePermissions()` |
