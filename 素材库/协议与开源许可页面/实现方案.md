# 协议与开源许可页面 · 实现方案

## 1. 功能效果

在设置页提供正式 App 常见的合规入口：

- 开源许可与致谢；
- 隐私说明；
- 项目主页 / 官网入口；
- 可扩展为用户协议、第三方 SDK 列表、版本信息页。

## 2. 实现原理

示例使用 `GlassDialog` 做同窗玻璃弹窗，避免系统 `Dialog` 无法采样主窗口 backdrop 的问题。文本内容可以直接写在 Kotlin 常量中，也可以从 Markdown / raw 资源读取。

## 3. 使用步骤

1. 拷贝 `代码/合规信息弹窗.kt`；
2. 在设置页维护一个 `LegalInfoType?` 状态；
3. 点击设置行时赋值；
4. 状态非空时展示 `LegalInfoDialog(type, onDismiss)`。

示例：

```kotlin
var legal by remember { mutableStateOf<LegalInfoType?>(null) }

PreferenceRow(
    icon = AppIcons.Shield,
    title = "开源许可与致谢",
    onClick = { legal = LegalInfoType.Licenses }
)

legal?.let { LegalInfoDialog(it) { legal = null } }
```

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 文案太长 | 改成单独页面或可滚动 Column |
| 想显示 Markdown | 加一个 Markdown 渲染组件，或预处理成 AnnotatedString |
| 项目主页打不开 | 使用 `Intent.ACTION_VIEW` 并捕获异常 |
