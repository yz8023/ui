# 主题配置导入导出 · 环境要求

## 依赖

- Android framework `org.json.JSONObject`
- Jetpack Compose Material 3
- 本项目的 `AppSettingsState`
- 本项目的 `PreferenceCard`、`PrimaryButton`、`SecondaryButton`

无需网络和存储权限。

## 需要修改的文件

```text
ui/screens/AppSettingsState.kt   # 增加 exportThemeJson / importThemeJson
ui/screens/SettingsScreen.kt     # 加入 ThemeConfigTransferCard
```

## 版本要求

| 项 | 要求 |
|---|---|
| minSdk | 任意现代 Android；本示例工程 26+ |
| Compose | Material 3 |
