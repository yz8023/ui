# 主题配置导入导出 · 实现方案

## 1. 功能效果

把当前 App 外观设置导出为 JSON，并支持从剪贴板导入恢复。适合：

- 用户跨设备同步主题；
- 开发者分享调好的玻璃参数；
- 调试时快速复现某套配色 / 圆角 / 动效设置；
- App 设置备份。

当前示例工程已接入到「设置 → 主题配置」。

## 2. 导出的字段

示例 JSON：

```json
{
  "schema": 1,
  "themeMode": "Dark",
  "palette": "Galaxy",
  "visualMode": "Glass",
  "reducedMotion": false,
  "motionDamping": 0.5,
  "wallpaperBackground": false,
  "glassOpacity": 0.55,
  "glassRefraction": 1.0,
  "cornerScale": 1.0,
  "customSeed": -12611616,
  "customSeedHex": "#FF3E8FE0",
  "customShade": 0.5
}
```

## 3. 实现原理

- `AppSettingsState.exportThemeJson()`：读取状态并生成 JSON；
- `AppSettingsState.importThemeJson(json)`：解析 JSON，逐项更新并持久化；
- `ThemeConfigTransferCard`：把导入 / 导出做成设置页卡片，使用系统剪贴板传递。

没有引入额外 JSON 库，直接使用 Android 自带 `org.json.JSONObject`。

## 4. 详细步骤

### 步骤 1：给状态类增加导出 / 导入方法

参考示例工程：

```text
android/app/src/main/java/com/monkeycode/liquidui/ui/screens/AppSettingsState.kt
```

把 `exportThemeJson()` 和 `importThemeJson()` 拷到你的设置状态类中。

### 步骤 2：拷贝 UI 卡片

```text
素材库/主题配置导入导出/代码/主题配置导入导出.kt
```

拷贝后修改 package，并在设置页调用：

```kotlin
ThemeConfigTransferCard(settings)
```

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 导入失败 | 确认剪贴板是完整 JSON |
| 旧版本字段不全 | 使用 `optXxx` 读取，缺省值保留当前设置 |
| 想导出到文件 | 可与「文件选择与分享」素材组合使用 |
