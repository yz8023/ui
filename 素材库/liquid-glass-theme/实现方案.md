# 液态玻璃主题 · 实现方案

> 功能点：给 App 套一层"真玻璃"视觉主题——面板半透明、模糊、折射背后的
> 色彩与内容，并支持多套配色一键换肤。

## 1. 功能效果

- 所有卡片 / 底栏 / 弹窗都呈现"液态玻璃"质感：背后有柔和渐变光斑（aurora），
  玻璃面采集并模糊 / 折射它。
- 7 套预设配色 + 1 套自定义取色（冰蓝 / 薄荷 / 落日 / 素灰 / 珊瑚 / 樱花 /
  星夜 / 自定义），色卡即点即换。
- 一套全局旋钮（透明度 / 折射率 / 圆角 / 昼夜 / 减少动效），设置页滑块实时调。

## 2. 实现原理

### 2.1 真玻璃：backdrop-android

普通"玻璃"是自绘的半透明 tint + 白色渐变描边，看起来像但"看不到背后"。
本项目采用与参考项目 dyparse 同款的 **`io.github.kyant0:backdrop-android`** 库，
做**真正的 backdrop 采样**：

1. 应用根部把装饰层（aurora 光斑 / 桌面壁纸）录制成一个 `Backdrop` 图形层。
2. `Modifier.liquidGlass` 在绘制时**采样**该层，依次叠加：
   - 软投影 `Shadow`
   - 采样内容经 `vibrancy()` + `blur()` + `lens()` 折射（`lens` 是 RuntimeShader，
     只在 Android 13+ 生效，低版本自动跳过）
   - 半透明 tint 填充（密度跟随透明度旋钮）
   - 顶部 specular 高光（模拟玻璃反光）

### 2.2 图层结构（AppRoot 中）

```
surfaceColor 底
 ├─ auroraBackdrop 层：AuroraBackground（或桌面壁纸）录制成层
 │     └─ 页面内玻璃面板采样它（折射身后色彩）
 ├─ contentBackdrop 层：页面内容单独录制
 │     └─ 悬浮底栏采样 combined(aurora, content)，内容从玻璃下滚过时被折射
 └─ LiquidBottomTabs（最顶）
```

为什么分两层：页面内面板背后只有光斑，采样 aurora 即可；底栏是唯一"有内容从
下方滚过"的玻璃，必须再叠加内容层，才能折射真实页面。

### 2.3 配色换肤：token + PaletteSeeds

全部视觉取值收敛成 token：

| token 文件 | 内容 |
|---|---|
| `Color.kt` | 中性色 / 强调色 / 7 套配色种子 / aurora 光斑色 |
| `Shape.kt` | 圆角 scale |
| `Type.kt` | 字号 / 字重分级 |

`Theme.kt` 里的 `PaletteSeeds` 为每套配色存 light/dark 的主色与容器色，
`schemeFor()` 组装成 Material3 `ColorScheme`。**改 `Color.kt` 一个文件即可整体换肤**。

### 2.4 三态视觉风格

`VisualMode` 三选一，一个开关切换：

- **Glass（玻璃）**：backdrop 采样 + 液态底栏（本素材的默认）。
- **Normal（普通）**：实心 Material 卡片 + 标准 `NavigationBar`，无玻璃。
- **MD3（Material You）**：Android 12+ 从壁纸动态取色的系统配色。

### 2.5 平滑换肤

`rememberAnimatedColorScheme` 用 `animateColorAsState` 对 `ColorScheme` 的
全部角色逐项交叉淡化，切换主题/昼夜时不闪眼。

## 3. 详细步骤

### 步骤 1：加依赖

`gradle/libs.versions.toml` 加入 backdrop-android（要求 compileSdk 36）：

```toml
kyant-backdrop = { module = "io.github.kyant0:backdrop-android", version = "2.0.0-alpha03" }
kyant-shapes = { module = "io.github.kyant0:shapes", version = "0.1.1" }
```

### 步骤 2：拷入 token 与主题文件

从 `代码/` 拷贝 `Color.kt / Shape.kt / Type.kt / Theme.kt / Glass.kt` 到你的
`ui/theme` 与 `ui/components` 目录，按你的包名改 package。

### 步骤 3：根部录制 backdrop

在 App 根组合里创建两层 backdrop，并用 `LocalGlassBackdrop` 暴露给子组件
（参考 `android/.../ui/navigation/AppRoot.kt` 的实现）。

### 步骤 4：给面板套皮肤

```kotlin
// 普通卡片
GlassCard {
    Text("玻璃卡片")
}

// 任意 Surface 套玻璃
Modifier.liquidGlass(shape = MaterialTheme.shapes.large)
```

### 步骤 5：接入设置页旋钮

用 `AppChrome` + `SharedPreferences` 持久化（示例见
`android/.../ui/screens/AppSettingsState.kt`）。

## 4. 常见问题

| 问题 | 原因 / 处理 |
|---|---|
| 玻璃没效果，面板是实心的 | `visualMode` 不是 Glass；或没提供 `LocalGlassBackdrop` |
| `lens()` 折射不生效 | `lens` 需 Android 13+（RuntimeShader），低版本库自动跳过，属正常降级 |
| 弹窗玻璃退化成 tint | 弹窗用了独立 Window 的 `Dialog`，跨窗口无法采样 backdrop；需用同窗浮层（见 `Dialogs.kt` 的 `GlassDialogHost`） |
| 依赖找不到 | backdrop 要求 compileSdk 36，`gradle.properties` 需 `android.suppressUnsupportedCompileSdk=36` |
