# 液态玻璃主题 · 环境要求

## 依赖

```toml
# gradle/libs.versions.toml
kyant-backdrop = { module = "io.github.kyant0:backdrop-android", version = "2.0.0-alpha03" }
kyant-shapes = { module = "io.github.kyant0:shapes", version = "0.1.1" }
```

```kotlin
// app/build.gradle.kts
implementation(libs.kyant.backdrop)
implementation(libs.kyant.shapes)
```

## 版本要求

| 项 | 要求 | 说明 |
|---|---|---|
| compileSdk | **36** | backdrop-android 强制要求 |
| minSdk | 26 | 玻璃可全版本运行，模糊/折射按平台自动降级 |
| Android 13+ | `lens()` 折射（RuntimeShader） | 低版本自动跳过 lens，保留"采样 + tint + 高光" |
| Kotlin | 2.3.x | backdrop 为 Kotlin 2.3 元数据 |
| Gradle / AGP | 8.11.1 / 8.7.3 | 示例工程锁定版本 |

## 需在 gradle.properties 添加

```properties
android.suppressUnsupportedCompileSdk=36
```

## 需要的文件

| 文件 | 说明 |
|---|---|
| `代码/Color.kt` | 色彩 token + 7 套配色种子 |
| `代码/Shape.kt` | 圆角 token |
| `代码/Type.kt` | 文字 token |
| `代码/Theme.kt` | `LiquidUITheme` + `AppChrome` 旋钮 + 平滑换肤 |
| `代码/Glass.kt` | `liquidGlass` 修饰符 + `GlassCard` / `GlassPill` + aurora 背景 |

根部 backdrop 录制参考示例应用 `ui/navigation/AppRoot.kt`，弹窗同窗浮层参考
`ui/components/Dialogs.kt`。
