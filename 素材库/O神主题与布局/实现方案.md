# O神主题与布局 · 实现方案（功能编号 F14）

> 一键切换到 suqi8/OShin（O神）的同款设计语言：**换的不只是颜色，而是整套布局**——
> 浅灰页面底、白色分组卡片、系统蓝、分节小标题、大标题页、左右翻页、悬浮胶囊底栏。
> 在示例 App 的「设置 → 风格 → 视觉风格」选「O神」即整页切换，随主题模式（浅/深）走。

## 1. 提取了 OShin 的什么（对照表）

提取对象是 OShin 公开仓库 `app/.../ui/` 界面层（其底座为 Miuix），逐项对应如下：

| OShin 原项目 | 本模板（F14） | 参数 |
|---|---|---|
| `ui/theme/Theme.kt`：`MiuixTheme` + colorMode 0/1/2 | `oshinColorScheme(dark)` 映射到 Material3 | 见 `代码/OShinTheme.kt`，随本模板 ThemeMode（系统/浅/深）联动 |
| Miuix 默认色：页底 #F7F7F7/#000、卡片 #FFF/#242424、主色 #3482FF | `OShinTokens` 同值落地 | 底栏强调另用 OShin 硬编码的 #0088FF/#0091FF |
| `components/Card.kt`：16dp 圆角、左右 16dp、实色无边 | `Modifier.liquidGlass` 在 OShin 模式变实色分组卡 + `OShinCard` | 卡片圆角 22dp→16dp 由主题形状切换驱动 |
| `components/FunArrow.kt`（标题+摘要+右文+箭头） | `OShinArrowRow` | 行内距 16dp、右文案灰色、箭头「›」 |
| `components/FunSwich.kt`（蓝开关行） | `OShinSwitchRow`（复用 CompactSwitch，选中色=主题蓝） | 开关蓝 #3482FF 系（深色 #0091FF） |
| Miuix `SmallTitle` 分组标题 | `OShinSmallTitle` + `SectionTitle` 在 O神模式变灰 | 左对齐 32dp（页边 16 + 行内 16） |
| `mainscreen/MainScreen.kt`：HorizontalPager 四页 | AppRoot 在 O神模式换成 `HorizontalPager` 翻页壳 | 页间滑动切换，底栏点击 `animateScrollToPage` 同步 |
| 页间切换模糊（offset×16dp Blur） | AppRoot 翻页时对非当前页做同等模糊（API 31+） | 与 OShin `rememberPageBlurModifier` 同参数 |
| `components/BottomTabs.kt`：悬浮玻璃胶囊底栏 | `OShinBottomTabs` | 左右 40dp、下 16dp、高 64dp、图标 24–28、标签 11–12sp、选中蓝 |
| `BlurredTopBarBackground`（72dp 顶部模糊带） | 本模板页面自带大标题（与 OShin 各页一致），壳层不另加顶栏 | 若你的页面没有大标题，用 `OShinPageHeader` 补 |

**没有照搬的**（有意差异，接入时须知）：OShin 的底栏滚动自动隐藏（其滚动状态与页面共享，
本模板页面各自持有 LazyColumn，未接全局联动）；底栏在 OShin 是 backdrop 真模糊采样，
本模板非玻璃壳层下用 72% 不透明卡面+阴影近似，内容滚过时可读性优先；
OShin 的 Xposed/Hook/模块业务、友盟、验证、关于页作者信息等一律不在提取范围。

## 2. 实现原理（切换如何做到「布局一起变」）

新增第 4 个 `VisualMode.OShin`，并让它同时驱动四层：

1. **颜色**：`LiquidUITheme` 在 OShin 时用 `oshinColorScheme(dark)`，覆盖 7 套 Palette；
2. **形状/排版**：同处切换为 `OShinShapes`（卡 16dp）与 `OShinTypography`；
3. **卡片材质**：`liquidGlass` 见 OShin 直接落成实色卡面——所有 GlassCard/设置卡/控件瞬间变分组白卡，不用逐页改；
4. **壳层布局**：`AppRoot` 见 OShin 时把 AnimatedContent 缩放切换换成 HorizontalPager 翻页，
   底栏换成 `OShinBottomTabs` 悬浮胶囊；`SectionTitle/PreferenceCard/PreferenceRow` 同步变 Miuix 分组样式。

状态仍只有一个来源：`AppSettingsState.visualMode`（持久化键 `visualMode`，主题 JSON 导入导出自动带上，无需新增字段）。

## 3. 接入步骤（往你自己的 Compose 工程里加）

1. 拷 `代码/OShinTheme.kt`（改 package）、`代码/OShinComponents.kt`（可选，按需用分组组件）；
2. 你的 `VisualMode`（或等价的风格枚举）加 `OShin` 一档，主题组合函数里：
   OShin 时 `colorScheme=oshinColorScheme(dark)`、形状/排版换 OShin 套；
3. 卡片容器加一条规则：OShin 时实色 `surfaceContainer` + 16dp，不要玻璃/阴影；
4. 壳层：OShin 时内容用 `HorizontalPager`（页数=你的标签数），底栏按 `OShinTokens`
   的 40/16/64dp 尺度做悬浮胶囊，选中色 #0088FF/#0091FF，标签点击滚动到对应页、
   翻页 `settledPage` 回写选中态；
5. 设置页把「O神」加进风格分段控件（本模板 `SegmentedTabs(VisualMode.entries)` 自动出现）；
6. 按下面验收清单逐项过。

## 4. 验收清单

- [ ] 设置里选「O神」：页面底变浅灰（深色纯黑）、卡片变白/深灰分组卡、强调变系统蓝，不重启生效
- [ ] 底栏变窄胶囊（左右留空、悬浮），点每个标签翻页到位，左右滑页后底栏选中跟着变
- [ ] 翻页过程中相邻页有轻微模糊（API 31+），停稳后当前页清晰
- [ ] 卡片圆角明显比玻璃模式小（16dp）、无玻璃高光/折射；分组标题变灰色小标题
- [ ] 切回玻璃/普通/MD3：颜色、圆角、底栏、翻页全部还原，无残留
- [ ] 深色模式走一遍：卡 #242424、底 #000、蓝 #0091FF，文字可读
- [ ] 杀进程重进仍是 O神（visualMode 已持久化）；导出主题 JSON 再导入能恢复

## 5. 失败指纹

| 现象 | 原因 | 改法 |
|---|---|---|
| 切了 O神只有颜色变了，底栏/布局没变 | 只接了第 1 层颜色，没接壳层（步骤 4）与卡片规则（步骤 3） | 四层缺一层都是半成品，按第 2 节逐层核对 |
| 卡片还是玻璃折射 | 卡片没走统一容器，或 OShin 判断写错模式 | 确认卡片都经同一材质函数且判断的是当前 `visualMode` |
| 翻页后底栏高亮不对 | 只在点击时更新选中，没监听 `settledPage` 回写 | 两处都要：点击滚页 + settled 回写 |
| 底部内容被胶囊挡住 | 页面列表底部 padding 不够 | 列表底部预留 ≥ 底栏 64+16+余量（本模板 108dp） |
| 圆角还是 22dp | 只换了 MaterialTheme 形状，卡片写死 22dp 的地方没跟随 | 写死圆角处按模式取 16dp（本模板 PreferenceCard 的做法） |
