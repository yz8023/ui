# O神主题与布局 · 环境要求（F14）

## 依赖

- 与液态玻璃主题（F03）相同：Jetpack Compose + Material3；**不需要**引入 Miuix 库
  （本功能是把 Miuix/OShin 的视觉参数映射到 Material3 token，引入原库反而会与模板组件体系冲突）。
- 翻页用 Compose Foundation 的 `HorizontalPager`（Compose BOM 自带，无新依赖）。
- 页间模糊用 `BlurEffect`，仅 API 31+ 生效，低版本自动跳过（不报错）。

## 版本要求

| 项 | 要求 |
|---|---|
| minSdk | 26（页间模糊 31+ 才有，余皆全版本） |
| compileSdk | 36（沿用模板基准） |
| Kotlin / Compose BOM | 2.3.10 / 2024.10.01（以 `android/gradle/libs.versions.toml` 为准） |

## 需要的文件

| 文件 | 说明 |
|---|---|
| `代码/OShinTheme.kt` | 色板 `oshinColorScheme`、布局尺度 `OShinTokens`、形状 `OShinShapes`、排版 `OShinTypography` |
| `代码/OShinComponents.kt` | `OShinCard/OShinSmallTitle/OShinArrowRow/OShinSwitchRow/OShinDivider/OShinPageHeader` |

## 需要改动的宿主文件（以示例工程为例）

| 文件 | 改动 |
|---|---|
| `ui/theme/Theme.kt` | `VisualMode` 加 `OShin`；`LiquidUITheme` 在该模式用 O神色板/形状/排版 |
| `ui/components/Glass.kt` | `liquidGlass` 加 OShin 分支：实色分组卡、无阴影高光 |
| `ui/components/Rows.kt` | 分组标题灰色化、设置卡 16dp 圆角、行图标去彩色底 |
| `ui/navigation/AppRoot.kt` | OShin 时 HorizontalPager + 页间模糊 + `OShinBottomTabs` 悬浮底栏 |
| 设置页 | 风格分段控件包含「O神」（枚举驱动即自动出现） |
