# 实现方式及方案

## 功能概述

首次启动时向用户展示应用介绍引导页，包含品牌 Logo、应用名称、标语、核心功能列表、免费声明、免责说明、开源仓库入口和"开始使用"主操作按钮。引导完成后不再显示，用户可随时在设置中重新查看。

## 技术方案

### 1. 触发条件

通过 `SharedPreferences` 持久化一个布尔标记 `onboarding_completed`（默认 `false`）。应用冷启动时读取该标记：

- `false` → 跳转到引导页；
- `true` → 直接进入主页。

点击"开始使用"后将标记设为 `true`，同一次会话不再重复显示。

### 2. 页面结构（从上到下）

| 区块 | 组件 | 说明 |
|------|------|------|
| 品牌区 | `Box` + `Image` + `Text` | 渐变 RoundedCornerShape(26dp) 背景 + 应用图标 96dp + 应用名称（HeadlineLarge）+ 标语（BodyLarge） |
| 功能列表 | `Column` + `OnboardingFeature` | 垂直排列 4 个条目，每行圆形图标底 + 标题 + 描述 |
| 免费声明卡 | `Card`（`tertiaryContainer`） | `Favorite` 爱心图标 + 加粗标题 + 副标题 |
| 免责声明卡 | `Card`（`surfaceContainerLow`） | `Shield` 盾牌图标 + 多行免责正文 |
| 开源仓库卡 | `Card` + `onClick` | 点击跳转浏览器打开 GitHub 仓库 |
| 底部主操作 | `Surface`（shadowElevation）+ `Button` | 全宽 52dp 高按钮，点击回调 `onFinish` |

### 3. 关键组件

#### `OnboardingFeature`（功能条目）

```
Surface(CircleShape, primaryContainer)
  └─ Icon(22dp, onPrimaryContainer)
Spacer(16dp)
Column
  ├─ Text（titleSmall, Medium）
  └─ Text（bodySmall, onSurfaceVariant）
```

#### `GitHubCard`（开源仓库卡）

- `Card.onClick` → `Intent.ACTION_VIEW(Uri)` → 系统浏览器；
- 使用 `Outlined.Code` + `Outlined.OpenInNew` 图标增强语义。

### 4. 样式特点

- **纯 Compose**，零 XML 布局；
- **Material 3** 颜色体系；
- 图标均为矢量图标（`Icons.Outlined.*`），无需额外 bitmap 资源；
- 字体层级遵循 Material 3 规范（`headlineLarge` / `bodyLarge` / `titleSmall` / `bodySmall` 等）；
- 底部按钮区域使用 `Surface` + `shadowElevation = 8.dp` 与可滚动内容区形成视觉分层。

### 5. 可扩展点

| 扩展方向 | 说明 |
|---------|------|
| 多页引导 | 将 `Column` 替换为 `HorizontalPager`，底部加页面指示器 |
| 跳过按钮 | 顶部右上角添加 `TextButton("跳过")`，点击同样调用 `onFinish` |
| 条件展示 | 根据用户网络状态或登录状态，动态增减功能列表条目 |
| 深色模式 | 本页面已适配深色模式（使用 `colorScheme` 统一颜色变量，无需额外处理） |
