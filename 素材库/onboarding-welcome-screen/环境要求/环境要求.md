# 环境要求

## 运行时

| 要求 | 版本 |
|------|------|
| minSdk | 21（Android 5.0 Lollipop） |
| targetSdk | 34（Android 14） |
| compileSdk | 36 |

## 依赖（build.gradle.kts）

```kotlin
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.compose)
}

android {
    buildFeatures { compose = true }
    compileOptions { sourceCompatibility = JavaVersion.VERSION_17 }
    kotlin { compilerOptions { jvmTarget.set(JvmTarget.fromTarget("17")) } }
}

dependencies {
    implementation(platform(libs.androidx.compose.bom))
    implementation(libs.androidx.ui)
    implementation(libs.androidx.ui.graphics)
    implementation(libs.androidx.ui.tooling.preview)
    implementation(libs.androidx.material3)
    implementation(libs.androidx.activity.compose)
}
```

## 关键依赖版本

- Compose BOM：`2024.06.00` 或更高
- Kotlin：`2.3.10` 或更高
- Gradle：`8.0+`
- JDK：17

## 接入步骤

1. 将 `OnboardingScreen.kt` 复制到你的 Compose UI 模块。
2. 在 `MainActivity.onCreate` 或应用启动入口判断是否展示：
   ```kotlin
   val prefs = getSharedPreferences("app_settings", Context.MODE_PRIVATE)
   val showOnboarding = prefs.getBoolean("onboarding_completed", false).not()
   if (showOnboarding) {
       setContent { OnboardingScreen(onFinish = { /* 写入完成标记 + 跳主页 */ }) }
   }
   ```
3. 用户点击"开始使用"后写入标记：
   ```kotlin
   prefs.edit().putBoolean("onboarding_completed", true).apply()
   ```
