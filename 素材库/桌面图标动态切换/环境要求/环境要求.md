# 环境要求

## 运行时

| 要求 | 版本 |
|------|------|
| minSdk | 16（`PackageManager.setComponentEnabledSetting` API 16+ 即可；如需自适应图标则 minSdk 26+） |
| targetSdk | 34（Android 14） |
| compileSdk | 36 |

> **注意**：`<adaptive-icon>` XML 格式要求 minSdk ≥ 26（Android 8.0 Oreo）。若需兼容更低版本，需保留传统 `mipmap-*` 目录中的 PNG 图标。

## AndroidManifest.xml 配置

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <application
        android:icon="@drawable/ic_launcher"
        android:roundIcon="@drawable/ic_launcher"
        ... >

        <!-- 主 Activity（经典图标，默认启用） -->
        <activity
            android:name=".MainActivity"
            android:exported="true"
            android:icon="@drawable/ic_launcher"
            android:roundIcon="@drawable/ic_launcher">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>

        <!-- 新图标（默认禁用） -->
        <activity-alias
            android:name=".MainActivityIcon2"
            android:enabled="false"
            android:exported="true"
            android:icon="@drawable/ic_launcher2"
            android:roundIcon="@drawable/ic_launcher2"
            android:label="@string/app_name"
            android:targetActivity=".MainActivity">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity-alias>

    </application>
</manifest>
```

## 所需资源文件

```
app/src/main/res/
├── drawable/
│   ├── ic_launcher.png          ← 经典图标前景（任意尺寸）
│   └── ic_launcher2.png         ← 新图标前景（任意尺寸）
└── mipmap-anydpi-v26/
    ├── ic_launcher.xml          ← 经典图标自适应 XML
    └── ic_launcher2.xml         ← 新图标自适应 XML
```

`mipmap-anydpi-v26/ic_launcher.xml` 内容：

```xml
<?xml version="1.0" encoding="utf-8"?>
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background" />
    <foreground android:drawable="@drawable/ic_launcher" />
</adaptive-icon>
```

`ic_launcher2.xml` 同理，将 `@drawable/ic_launcher` 替换为 `@drawable/ic_launcher2`。

## 依赖

此功能无需额外第三方依赖，仅使用 Android SDK 内置 API。

| API | 用途 |
|-----|------|
| `PackageManager.setComponentEnabledSetting` | 启用/禁用 activity-alias |
| `ComponentName` | 构造组件名 |
| `SharedPreferences` | 持久化变体值 |

## 接入步骤

### Compose 方案

1. 复制 `IconSwitcher.kt` 到你的 Compose UI 模块；
2. 在设置页 `Row` / `Column` 中调用 `IconSwitcher(currentVariant, onVariantChanged)`；
3. `onVariantChanged` 回调中持久化 + 调用 `IconSwitchHelper.switchAndSave(context, variant)`。

### 原生方案

1. 直接在 Activity / Fragment 中调用：
   ```kotlin
   IconSwitchHelper.switchAndSave(this, 1)  // 切换到新图标
   IconSwitchHelper.switchAndSave(this, 0)  // 切回经典图标
   ```
2. 冷启动时读取：`val variant = IconSwitchHelper.getSavedVariant(this)`。
