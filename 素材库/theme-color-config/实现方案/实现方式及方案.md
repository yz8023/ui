# 实现方式及方案

## 功能概述

在"设置 → 主题与外观"页面提供三项外观配置：外观模式（跟随系统 / 浅色 / 深色）、主题色（动态色彩跟随壁纸 / 默认蓝色 / 自定义颜色）、桌面图标样式切换。所有设置即时生效并持久化。

## 技术方案

### 1. 整体架构

```
ThemeScreen（Compose 页面）
  ├── 外观模式  ── ThemeController.setDarkMode() ──→ SettingsRepository
  ├── 主题色    ── ThemeController.setColorMode() / setSeedColor()
  ├── 桌面图标  ── PackageManager.setComponentEnabledSetting()
  └── 调色盘    ── ColorPickerDialog（SatVal + Hue 滑块）
ThemeController（单例，mutableStateOf）
  └── SettingsRepository（SharedPreferences 读写）
ComposeEmptyActivityTheme（@Composable 顶层主题）
  └── seedColorScheme（基于 HCT/SchemeTonalSpot 生成完整颜色方案）
```

### 2. 外观模式

三种模式通过整数枚举存储：

| 值 | 含义 |
|----|------|
| 0 | 跟随系统（`isSystemInDarkTheme()`） |
| 1 | 始终浅色 |
| 2 | 始终深色 |

`SmoothFilterChip` 实现胶囊单选：选中态用 `secondaryContainer` 底色，未选中态显示 1dp 描边，颜色过渡动画时长 200ms（`LinearEasing`）。

### 3. 主题色（三模式）

| 模式 | 值 | 条件 | 颜色来源 |
|------|-----|------|---------|
| 动态色彩 | 0 | Android 12+（`Build.VERSION.SDK_INT >= S`） | `dynamicLightColorScheme()` / `dynamicDarkColorScheme()`（从系统壁纸取色） |
| 默认蓝色 | 1 | 任意版本 | 预设 `lightScheme` / `darkScheme`（`primary = #415F91`） |
| 自定义颜色 | 2 | 任意版本 | `seedColorScheme(seedArgb, dark)`（基于 HCT Tonal Spot 算法生成） |

#### 自定义颜色流程

1. 用户点击"自定义"按钮 → 弹出 `ColorPickerDialog`；
2. `SatValPanel`（可拖拽饱和度/明度方块）+ `VerticalHueSlider`（可拖拽色相条）让用户选色；
3. 实时显示 HEX 输入框和颜色预览块；
4. 点击"应用" → `ThemeController.setSeedColor(context, argb)` 写入持久化，切换颜色模式为 2，Compose 自动重组刷新全页面颜色。

#### 颜色方案生成（HCT + Tonal Spot）

```kotlin
val scheme = SchemeTonalSpot(Hct.fromInt(seedArgb.toInt()), dark, 0.0)
```

基于 `material-color-utilities` 的 `SchemeTonalSpot` 从单一种子色生成 19 组完整颜色（primary / onPrimary / primaryContainer / ... / surfaceContainerHighest），覆盖 light / dark 两套方案。

### 4. 桌面图标切换

**机制：activity-alias 动态启用/禁用**

```
AndroidManifest.xml
  ├── <activity android:name=".MainActivity"     android:enabled="true"  android:icon="@drawable/icon" />
  └── <activity-alias                             android:enabled="false" android:icon="@drawable/icon2" />
           android:name=".MainActivityIcon2"
           android:targetActivity=".MainActivity"
```

- `MainActivity`：默认 launcher，使用 `@drawable/icon`（经典图标）；
- `MainActivityIcon2`：别名 launcher，使用 `@drawable/icon2`（新图标），默认 `enabled="false"`；
- 切换时通过 `PackageManager.setComponentEnabledSetting()` 交替启用/禁用两者，`DONT_KILL_APP` 避免重启进程。

**变体值**

| 值 | 显示图标 |
|----|---------|
| 0 | `@drawable/icon`（经典） |
| 1 | `@drawable/icon2`（新图标） |

变体值同步存入 `SettingsRepository.appIconVariant`，下次冷启动从 SharedPreferences 读取恢复。

### 5. 可折叠卡片动画

主题色卡片和桌面图标卡片均采用相同的可折叠展开动画：

- 展开高度由 `Animatable(progress)` 驱动，progress ∈ [0, 1]；
- `onSizeChanged` 获取内容真实高度，`with(density) { contentHeightPx * progress.toDp() }` 计算动画高度；
- 同时用 `graphicsLayer { alpha = expandProgress.value }` 控制透明度，实现高度+透明度同步动画；
- `Animatable` 支持快速连续点击时打断上一轮动画，平滑过渡到新目标。
