## 换算公式（参考 motion-web 与 Framer Motion 文档）

```text
dampingRatio = damping / (2 * sqrt(stiffness * mass))
```

对应关系：

| 本素材预设 | 对应 Framer Motion 手感 |
|---|---|
| `gentle` | gentle |
| `standard` | default |
| `snappy` | snappy |
| `bouncy` | bouncy |
| `heavy` | heavy |
| `stiff` | stiff |
