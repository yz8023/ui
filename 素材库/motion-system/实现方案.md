# 动效系统 · 实现方案

> 功能点：一套 token 化的交互动效系统——全局弹簧阻尼、按压冲击、常态呼吸、
> 错峰入场，全部收敛成统一 token，一处改全应用动效跟着变。

## 1. 功能效果

- **全局阻尼旋钮**：设置页一个滑块，重调全应用所有弹簧（越低越弹）。
- **按压冲击**：按钮/卡片按下时轻微压扁（`pressScale`），触发时抖动（`impactShake`）。
- **常态呼吸**：界面元素有极其轻微的持续缩放，避免"死板"。
- **错峰入场**：列表项逐个入场（`StaggeredReveal`），改一个数字即可调密度。
- **减少动效保障**：打开「减少动效」后物理动画退化为临界阻尼，内容始终可见。

## 2. 实现原理

### 2.1 token 全部收敛在 `Motion.kt`

- 时长 scale（90ms ~ 1200ms，6 档）。
- 缓动字典（expo / quart / back / circ 等 7 个 cubic-bezier）。
- 弹簧预设（gentle / standard / snappy / bouncy / heavy / stiff），从
  Framer Motion 的 `(stiffness, damping)` 记法换算成 Compose 的
  `(dampingRatio, stiffness)`：

  ```
  dampingRatio = damping / (2 * sqrt(stiffness * mass))
  ```

- 全局阻尼 `motionDamping`：`Motion.DampedRatio(base)` 会把基准阻尼比乘以一个
  由旋钮决定的倍率，所有弹簧读它，**一处调整全应用生效**。

> 约定：所有调用点禁止写临时 `spring(...)` 魔法数，一律从 `Motion` 取 token。

### 2.2 常用动效 Modifier（`Modifiers.kt`）

| Modifier | 效果 | 关键点 |
|---|---|---|
| `pressScale` | 按压压扁 | 用 `snappy` 弹簧，非 ripple |
| `impactShake` | 冲击抖动 | 两轴不同频率 + 振幅线性衰减到 0，避免糊成一片 |
| `idleBreathing` | 常态呼吸 | 两轴略不同频，避免同频脉冲感 |
| `StaggeredReveal` | 错峰入场 | 终态为默认值，`enabled=false` 时内容直接可见 |

### 2.3 手势物理（`DampedDragAnimation` / `InteractiveHighlight`）

- `DampedDragAnimation`：可拖动的弹簧动画，支持拖动中实时跟随、松手按阈值吸附、
  按压缩放、速度拉伸（保体积）。
- `InteractiveHighlight`：specular 高光跟随手指位置。
- `DragGestureInspector`：统一的手势信息采集（拖拽 / 速度 / 按压）。

### 2.4 减少动效降级

`AppSettingsState.reducedMotion` 为 true 时：

- 弹簧统一替换为临界阻尼（`Motion.CriticalDamping`）或 0ms tween；
- `StaggeredReveal` 等入场动画的 `enabled=false`，内容直接处于终态可见。

> 重要：接入 `StaggeredReveal` 时必须从 `LocalAppChrome.reducedMotion` 取值
> 传入 `enabled`，否则减少动效模式下内容可能不可见。

## 3. 详细步骤

### 步骤 1：拷入代码

从 `代码/` 拷贝 5 个文件到 `ui/motion/`，按你的包名改 package。

### 步骤 2：接入全局阻尼旋钮

在 App 根组合初始化一次：

```kotlin
SideEffect { Motion.motionDamping.floatValue = settings.motionDamping }
```

### 步骤 3：使用动效

```kotlin
// 按压反馈 + 错峰入场 + 呼吸
Modifier.pressScale(interactionSource)
StaggeredReveal(index = 0, enabled = !chrome.reducedMotion) { GlassCard { ... } }

// 触发一次冲击
var shakeTrigger by remember { mutableStateOf<Boolean?>(null) }
Modifier.impactShake(trigger = shakeTrigger)
```

### 步骤 4：接减少动效

从 `LocalAppChrome.current.reducedMotion` 取值，传给所有入场动效的 `enabled`。

## 4. 常见问题

| 问题 | 原因 / 处理 |
|---|---|
| 阻尼滑块拖了没反应 | `DampedDragAnimation` / `InteractiveHighlight` 的 `remember` key 必须包含 `damping`（见代码注释），否则规格被冻结 |
| 减少动效后内容消失 | `StaggeredReveal` 的 `enabled` 没接 `reducedMotion` |
| 冲击抖成糊 | `impactShake` 两轴频率差异不够大或振幅不衰减；一次冲击只挂一个 |
| 想要更弹的手感 | 调低 `motionDamping` 或换 `bouncy` 预设 |
