# 动效系统 · 环境要求

## 依赖

纯 Compose 实现，**无第三方动画库**，仅依赖 Compose 运行时：

```kotlin
implementation(platform(libs.androidx.compose.bom))
implementation(libs.androidx.compose.ui)
implementation(libs.androidx.compose.material3)
```

## 版本要求

| 项 | 要求 | 说明 |
|---|---|---|
| minSdk | 21+（示例为 26） | 动效本身无高版本 API 要求 |
| Compose BOM | 2024.10.01（示例） | 低版本需确认 `Spring` / `Animatable` API 兼容 |

## 需要的文件

| 文件 | 说明 |
|---|---|
| `代码/Motion.kt` | 全部 token：时长 / 缓动 / 弹簧 / 全局阻尼 / stagger |
| `代码/Modifiers.kt` | `pressScale` / `impactShake` / `idleBreathing` / `StaggeredReveal` |
| `代码/DampedDragAnimation.kt` | 可拖动弹簧动画（底部导航等活动胶囊用） |
| `代码/InteractiveHighlight.kt` | 高光跟随手指 |
| `代码/DragGestureInspector.kt` | 手势信息采集 |

## 接线约定

- 全局阻尼：App 根 `SideEffect { Motion.motionDamping.floatValue = settings.motionDamping }`。
- 减少动效：所有入场动效的 `enabled` 必须读 `LocalAppChrome.reducedMotion`。
- 动效调用点禁止写临时 `spring(...)` 魔法数，一律取 `Motion` token。
