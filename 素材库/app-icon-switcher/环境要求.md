# 应用图标切换 · 环境要求

## 依赖

- **Android 项目**（Kotlin / Java 均可，本功能与 Compose 无关）
- 一个真实主界面 Activity（`targetActivity`），如 `MainActivity`

## 版本要求

| 项 | 要求 | 说明 |
|---|---|---|
| minSdk | 任意（本示例为 26） | activity-alias 方案全版本可用 |
| targetSdk | 31+ 建议 | API 31+ 强制 LAUNCHER 组件 `exported=true` |
| Adaptive Icon | minSdk 26+ 直接可用 | `mipmap-anydpi-v26` 无需 PNG 兜底 |

> 若使用 Android 13+ 的 `setApplicationIcon`（方案 B），仅限 API 33+，
> 且属于 RESTRICTED API，普通应用基本无法通过平台门禁，本素材不采用。

## 需要修改的文件（对照示例应用）

| 文件 | 用途 |
|---|---|
| `AndroidManifest.xml` | 声明 `<activity-alias>`，给每个图标一个 launcher 入口 |
| `res/mipmap-anydpi-v26/*.xml` | 每套图标的 Adaptive Icon |
| `res/drawable/ic_launcher_foreground_*.xml` | 每套图标的前景矢量图 |
| `res/values/colors.xml` | 每套图标的背景色 |
| `AppIconSwitcher.kt` | 切换逻辑 + 设置页选择 UI |

## 构建

```bash
cd android
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```
