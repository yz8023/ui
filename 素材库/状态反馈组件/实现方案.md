# 状态反馈组件 · 实现方案

## 1. 功能效果

提供 App 常见的状态界面：

- `LoadingState`：加载说明 + 骨架屏；
- `SkeletonLine`：可单独放入列表、卡片、详情页；
- `EmptyState`：空内容占位；
- `ErrorState`：失败说明 + 可选重试动作；
- `SuccessBanner`：成功反馈；
- `OfflineBanner`：网络断开 / 离线提示；
- `InfoBanner`：普通信息提示；
- `StatTile`：首页数字指标卡。

## 2. 实现原理

状态反馈不是业务逻辑，而是业务状态的统一呈现层。所有组件都遵守三条约定：

1. 卡片、骨架和 Banner 复用 `liquidGlass`，视觉风格自动跟随玻璃 / 普通 / MD3；
2. 加载态只做轻量透明度呼吸，不阻塞用户；
3. 错误态必须保留操作入口，例如“重试”、“打开设置”、“重新导入”。

## 3. 详细步骤

### 步骤 1：拷贝代码

将 `代码/状态反馈组件.kt` 拷入你的工程，例如：

```text
app/src/main/java/你的包名/ui/components/Feedback.kt
```

并把文件顶部的 `package` 改成你的实际包名。

### 步骤 2：准备前置组件

该文件依赖：

- `liquidGlass`：来自「液态玻璃主题」；
- `PrimaryButton` / `SecondaryButton`：来自「玻璃常用组件」，仅在你写 action 时需要；
- `idleBreathing`：来自「动效系统」。

如果你的项目不使用玻璃主题，也可以把 `liquidGlass(...)` 替换成普通 `background(...)`。

### 步骤 3：在页面里使用

```kotlin
GlassCard {
    LoadingState(
        title = "加载数据",
        message = "正在同步本地缓存。"
    )
}
```

```kotlin
ErrorState(
    title = "加载失败",
    message = "网络连接不可用，请稍后重试。",
    action = { SecondaryButton(onClick = retry) { Text("重试") } }
)
```

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 骨架屏太亮 | 调低 `SkeletonLine` 的 alpha 或 tint |
| 页面没有玻璃效果 | 确认根组件提供了 `LocalGlassBackdrop`，或使用普通模式降级 |
| 错误态没有操作 | 给 `ErrorState` 传入 `action`，不要只显示文案 |
