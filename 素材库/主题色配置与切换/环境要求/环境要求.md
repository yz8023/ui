# 环境要求

## 运行时

| 要求 | 版本 |
|------|------|
| minSdk | 21（Android 5.0 Lollipop） |
| targetSdk | 34（Android 14） |
| compileSdk | 36 |
| 动态色彩 | 仅 Android 12+（API 31+）支持，低版本自动回退到默认色 |

## 依赖（build.gradle.kts）

```kotlin
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.compose)
}

android {
    buildFeatures { compose = true }
    compileOptions { sourceCompatibility = JavaVersion.VERSION_17 }
    kotlin { compilerOptions { jvmTarget.set(JvmTarget.fromTarget("17")) } }
}

dependencies {
    implementation(platform(libs.androidx.compose.bom))
    implementation(libs.androidx.ui)
    implementation(libs.androidx.ui.graphics)
    implementation(libs.androidx.ui.tooling.preview)
    implementation(libs.androidx.material3)
    implementation(libs.androidx.activity.compose)
    // material-color-utilities（HCT / SchemeTonalSpot）
    implementation("com.google.android.material:material:1.12.0")
}
```

## 关键依赖版本

- Compose BOM：`2024.06.00` 或更高
- Kotlin：`2.3.10` 或更高
- material-color-utilities（含在 `com.google.android.material:material` 中）：`1.12.0`
- Gradle：`8.0+`
- JDK：17

## AndroidManifest.xml 配置（桌面图标切换）

```xml
<activity
    android:name=".MainActivity"
    android:exported="true"
    android:icon="@drawable/ic_launcher"
    android:roundIcon="@drawable/ic_launcher">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>

<!-- 图标变体（默认禁用） -->
<activity-alias
    android:name=".MainActivityIcon2"
    android:enabled="false"
    android:exported="true"
    android:icon="@drawable/ic_launcher2"
    android:roundIcon="@drawable/ic_launcher2"
    android:label="@string/app_name"
    android:targetActivity=".MainActivity">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity-alias>
```

需要在 `res/drawable/` 下放置 `ic_launcher.png` 和 `ic_launcher2.png`（两套应用图标前景）。

## 接入步骤

1. 将 `ThemeScreen.kt`、`SettingsRepository.kt`、`ThemeController.kt` 复制到你的项目。
2. 在 `MainActivity` 或宿主页的 `setContent` 外层包裹 `AppTheme {}`。
3. 在导航路由中注册 `ThemeScreen` 页，进入时调用 `ThemeController.init(context)`（幂等，重复调用安全）。
4. 在应用任何 Activity / Compose 层级中读取 `ThemeController.darkMode` / `colorMode` / `seedColor` 即可。
