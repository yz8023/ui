# 底部导航栏 · 环境要求

## 依赖（与液态玻璃主题共用）

```toml
# gradle/libs.versions.toml
kyant-backdrop = { module = "io.github.kyant0:backdrop-android", version = "2.0.0-alpha03" }
kyant-shapes = { module = "io.github.kyant0:shapes", version = "0.1.1" }
```

## 前置素材（需一并拷入）

| 素材 | 来源 | 说明 |
|---|---|---|
| 液态玻璃主题 | `素材库/液态玻璃主题/` | 提供 `LocalAppChrome`、`LocalGlassBackdrop`、`liquidGlass` |
| 动效系统 | `素材库/动效系统/` | 提供 `DampedDragAnimation`、`InteractiveHighlight`、`Motion` |

## 版本要求

| 项 | 要求 |
|---|---|
| compileSdk | 36（backdrop 强制） |
| minSdk | 26 |
| 玻璃降级 | `VisualMode.Normal/Md3` 时自动用 Material3 `NavigationBar`，无需额外处理 |

## 需要的文件

| 文件 | 说明 |
|---|---|
| `代码/LiquidBottomTabs.kt` | 液态玻璃底部导航组件（含 `LiquidBottomTab`） |
| `代码/AppRoot_接线示例.kt` | 根部接线示例：两层 backdrop + 玻璃/普通双模式切换 |

## 关键接线点

- 根部需录制 `auroraBackdrop` 与 `contentBackdrop`，底栏采样二者 combined。
- 页面列表 `contentPadding(bottom ≈ 108.dp)`，内容才能从玻璃下滚过。
