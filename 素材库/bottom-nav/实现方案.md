# 底部导航栏 · 实现方案

> 功能点：可拖拽、带弹簧阻尼的"液态玻璃"底部导航栏；玻璃模式用玻璃质感，
> 关闭玻璃时自动降级为标准 Material3 `NavigationBar`。

## 1. 功能效果

- 一条半透明的胶囊容器，模糊并折射从它下方滚过的内容。
- 活动胶囊（指示器）在标签之间**弹簧滑动**，支持整条拖动：按索引 0.5 阈值
  松手自动吸附到最近标签。
- 按压时活动胶囊放大，拖动时按速度轻微拉伸（保体积），specular 高光跟随手指。
- 玻璃开关关闭（`VisualMode.Normal/Md3`）时自动换成实心 `NavigationBar`。

## 2. 实现原理

组件是参考项目液态 tab 的 Compose 移植，采样真实 `Backdrop` 层（同液态玻璃主题）：

```
LiquidBottomTabs(backdrop = combined(aurora, content))
 ├─ 1. 透明容器胶囊：vibrancy + blur(4dp) + lens，折射滚过内容
 ├─ 2. 隐藏的强调色副本：录制进 tabsBackdrop，活动胶囊按压时采样
 └─ 3. 移动玻璃胶囊：采样 combined(backdrop, tabsBackdrop)，弹簧跟随 + 按压缩放
```

关键动效部件：

| 部件 | 作用 |
|---|---|
| `DampedDragAnimation` | 活动胶囊的弹簧滚动：按压缩放、拖动回弹、松手吸附 |
| `InteractiveHighlight` | specular 高光跟随手指位置 |
| `Motion.DampedRatio(...)` | 全局阻尼旋钮，一处调整所有弹簧 |

降级逻辑：`LocalAppChrome.visualMode != Glass` 时，`AppRoot` 渲染
`SolidBottomTabs`（Material3 `NavigationBar`），玻璃机制整体停用。

## 3. 详细步骤

### 步骤 1：准备依赖

底部导航栏依赖液态玻璃主题的 `backdrop-android`，以及动效系统的
`DampedDragAnimation` / `InteractiveHighlight` / `Motion`。先按对应素材搭好。

### 步骤 2：拷入组件

从 `代码/` 拷贝 `LiquidBottomTabs.kt` 到你的 `ui/components`。

### 步骤 3：接入 App 根

```kotlin
// 需要有 auroraBackdrop + contentBackdrop 两层（见 液态玻璃主题/AppRoot）
LiquidBottomTabs(
    selectedTabIndex = { selectedIndex },
    onTabSelected = { selectedIndex = it },
    backdrop = rememberCombinedBackdrop(auroraBackdrop, contentBackdrop),
    tabsCount = screens.size,
    modifier = Modifier.align(Alignment.BottomCenter).padding(bottom = 14.dp)
) {
    screens.forEachIndexed { index, screen ->
        LiquidBottomTab(onClick = { selectedIndex = index }, index = index) {
            Icon(screen.icon, ...)
            Text(screen.title, ...)
        }
    }
}
```

### 步骤 4：内容预留底部 padding

页面列表底部留 ~108.dp `contentPadding`，让内容能从玻璃下滚过、被折射。

## 4. 常见问题

| 问题 | 原因 / 处理 |
|---|---|
| 底栏是实心的 | `visualMode` 未切到 Glass |
| 内容不从玻璃下滚过 | 列表 `contentPadding(bottom = 108.dp)` 不够 |
| 拖动没手感 / 卡顿 | 依赖动效系统文件的 `Motion` token，确认已拷入 |
| 标签项太多挤压 | `LiquidBottomTab` 默认最小宽 76dp，多标签可调小 |
