## 3. 12 条里哪些来自视频、哪些是本仓库补足

| 编号 | 术语 | 来源判定 |
|---|---|---|
| P01 | Alert | ✅ 视频简介点名 |
| P02 | Toast | ✅ 视频简介点名 |
| P03 | Modal | ✅ 视频简介点名 |
| P04 | Drawer | ✅ 视频简介点名 |
| P05 | Popconfirm | ✅ 视频简介点名 |
| P06 | Tooltip | ✅ 视频简介点名 |
| P07 | Snackbar | ⚠️ 本仓库补足（视频页面文字未点名） |
| P08 | Notification | ⚠️ 本仓库补足 |
| P09 | Popover | ⚠️ 本仓库补足 |
| P10 | BottomSheet / ActionSheet | ⚠️ 本仓库补足 |
| P11 | Loading / Progress | ⚠️ 本仓库补足 |
| P12 | Badge / Dot | ⚠️ 本仓库补足 |

补足的 6 条按「同族、且移动端做 App 必然会遇到」的标准挑选：Snackbar 与 Toast 是常被混用的一对、
Notification 是应用外提示、Popover 是 Tooltip 的富内容版、BottomSheet/ActionSheet 是移动端版的
Drawer/菜单、Loading 与 Badge 属提示族里的「状态类」。**视频里真实的 12 条可能与这 6 条不完全一致**
（例如可能讲的是 Message、Confirm、Dialog、Progress、Spin、Tag 之类），
看过视频的人若发现出入，以视频为准并回来改 `strings.xml`（术语文案 `ot_p*_*`）与本文件。

App 内与文档里都已标注这个区分：详情页底部来源说明写明「P01–P06 出自视频简介点名，
P07–P12 为本仓库补足的同族术语」。

## 4. 其余内容的著作权口径

- 12 条的**定义、什么时候用、和邻居的区别、Android/Compose 对应、反例、参数、提示词**
  全部为本仓库独立撰写，不是视频文案的复制或改写；视频的主题与 6 个术语名是唯一的输入。
- 视频为**网页（HTML/CSS/JS）演示**，本仓库演示为 **Jetpack Compose 独立实现**，
  没有搬运其网页代码、画面、字幕或截图；提示词里同时给了 Web 与 Android 两套写法，
  是因为术语本身来自 Web 体系，而本模板是 Android 模板。
