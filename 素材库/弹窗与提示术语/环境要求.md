# 弹窗与提示术语 · 环境要求

> 基准以 `android/gradle/libs.versions.toml` 为唯一可信来源；本文件只列本模块**额外**要注意的点。

## 1. 版本基准（示例 App 实测）

| 项 | 值 |
|---|---|
| JDK | 17 |
| compileSdk | 36 |
| minSdk | **26**（P08 通知渠道 `NotificationChannel` 与 `Notification.Builder(context, channelId)` 的硬门槛） |
| targetSdk | 35 |
| Kotlin | 2.3.10 |
| AGP | 8.7.3 |
| Compose BOM | 2024.10.01（Material3 1.3.x） |
| Gradle | 8.11.1 |

`minSdk < 26` 时：P08 必须自己加 `if (SDK_INT >= 26)` 分支并给旧版本走
`Notification.Builder(context)`（已废弃）或 `NotificationCompat`；其余 11 条不受影响。

## 2. 新增依赖

**无。** 只用 Compose BOM 与 AndroidX 已有工件：

| 能力 | 来源 |
|---|---|
| `AlertDialog` / `DropdownMenu` / `SnackbarHost(State)` / `ModalBottomSheet` / `LinearProgressIndicator` / `CircularProgressIndicator` / `HorizontalDivider` / `OutlinedTextField` / `Surface` / `Text` / `TextButton` / `Icon` | `androidx.compose.material3:material3` |
| `Dialog` / `DialogProperties` | `androidx.compose.ui:ui`（`androidx.compose.ui.window`） |
| `BackHandler` / `rememberLauncherForActivityResult` | `androidx.activity:activity-compose` |
| `combinedClickable`（长按触发 Tooltip） | `androidx.compose.foundation:foundation` |
| `animateFloatAsState` / `tween` | `androidx.compose.animation:animation-core` |
| `Toast` / `Notification*` / `NotificationManager` / `Build` | Android 框架，无需依赖 |
| `delay` / `launch`（自动消失、模拟耗时） | `kotlinx-coroutines`（随 Compose 传递依赖） |

不需要 Snackbar/BottomSheet/Popup 相关的第三方库。

## 3. 需要的注解开关

| 注解 | 用在哪 | 不加会怎样 |
|---|---|---|
| `@OptIn(ExperimentalMaterial3Api::class)` | P10 的 `ModalBottomSheet` + `rememberModalBottomSheetState` | 编译报错：experimental API 未 opt-in |
| `@OptIn(ExperimentalFoundationApi::class)` | P06 的 `combinedClickable(onLongClick = …)`；目录卡片与详情页的长按复制按钮 | 同上 |

本模块**刻意没用** `TooltipBox`（M3 实验 API）与 `ExposedDropdownMenuBox`：
前者实验性且行为不可控，后者语义是「选择器」不是 Popover。改用 `DropdownMenu` + 长按触发，
两者都是稳定 API，抄进宿主不会因为 BOM 升级而炸。

## 4. 权限与隐私

| 条目 | 权限 | 说明 |
|---|---|---|
| P08 Notification | `POST_NOTIFICATIONS`（Manifest 声明 + Android 13+ 运行时申请） | 未授权时 `notify()` 静默失败，所以演示里未授权就禁用发送按钮并给申请入口。示例 App 的 Manifest 已声明该权限 |
| 其余 11 条 | 无 | 不需要网络、存储、剪贴板读取权限 |

P02/P05/P07/P09 的「复制/撤销」等动作只在内存与界面状态里发生，不落盘；
详情页的提示词复制走系统剪贴板**写入**（无需权限）。

## 5. 资源依赖

| 资源 | 用在哪 | 宿主替换方式 |
|---|---|---|
| `R.drawable.ic_stat_launcher` | P08 通知小图标 | 换成你自己的纯色透明底图标（通知小图标必须是单色，彩色图会糊成白块） |
| `AppIcons.Notifications` / `AppIcons.Settings` / `AppIcons.RotateRight` / `AppIcons.Shield` / `AppIcons.Widgets` | P06 / P08 / P09 / P12 的图标 | 换成 Material Icons 或你自己的矢量图，只影响观感不影响逻辑 |
| `GlassCard` / `SectionTitle` | 目录与详情的卡片容器、分区小标题 | 换成 `Surface` / `Text` 即可 |

## 6. 已知平台差异

- **系统 Toast 样式**：Android 12+ 系统 Toast 在应用处于后台时不显示，且文本长度、样式受限；
  需要品牌样式时用演示里的「自绘轻提示」，语义保持不变（不可交互、自动消失）。
- **ModalBottomSheet 两档高度**：`skipPartiallyExpanded = false` 才有半展开档；
  内容很少时半展开会显得空，可按内容高度改成 `true`。
- **DropdownMenu 锚定**：自动在空间不足时翻到触发元素上方；若你的触发元素在可滚动列表里，
  滚动时菜单不会跟随（Compose 的行为），要么滚动即关，要么改用 `Popup` 自行定位。
- **Drawer 自绘版**：演示用 `offset { IntOffset(…) }` + `animateFloatAsState`，
  不依赖 `ModalNavigationDrawer`；若要手势滑开，需自己加 `draggable`/`pointerInput`。
- **深浅色**：全部颜色走 `MaterialTheme.colorScheme`；P12 角标用 `error` + `onError`，
  深色模式下描边对比度足够（演示里没有额外描边，宿主图标较花时建议加 2dp 背景色描边）。
- **O神（Miuix）模式**：`SectionTitle` 会自动切成 Miuix 分组小标题；其余布局不受影响。
- **字体缩放**：P12 角标字号固定 10sp、P10 动作项固定内边距，系统字体放到最大时角标可能变宽，
  已用 `99+` 上限兜住，不会出现四位数。
