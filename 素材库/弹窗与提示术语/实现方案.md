# 弹窗与提示术语 · 实现方案

> 对应手册 **F17**，条目编号 **P01–P12**（P 编号独立于手册 F 编号与 UI2 的 F 编号，
> 引用时写「P05」，不要写成「F05」）。
> 出处与口径见 `参考来源.md`，运行环境见 `环境要求.md`。

## 1. 这套东西解决什么

「加个弹窗」是需求描述里最省事、也最容易做错的一句话：
Alert、Toast、Modal、Drawer、Popconfirm、Tooltip、Snackbar、Notification、Popover、
BottomSheet、Loading、Badge 是十二种**不同强度、不同用途**的反馈，
说错术语，AI 或同事就会给你做出四不像——该不打断的做成了阻塞框，该给撤销的做成了 Toast。

本模块把 12 个术语做成三件事：

1. **定义 + 什么时候用 + 和邻居的区别**（术语课的核心价值就在「区别」）；
2. **Android / Jetpack Compose 的真实可操作演示**（真 Toast、真 AlertDialog、真 Dialog、
   真 DropdownMenu 锚定、真 SnackbarHost 可撤销、真 NotificationManager 发送、
   真 ModalBottomSheet、真三档加载进度）；
3. **可直接发给 AI 的提示词**（Web 与 Android 双写法 + 自检项），长按即复制。

| 编号 | 术语 | 中文 | 类别 | 一句话 |
|---|---|---|---|---|
| P01 | Alert | 警告框 | 阻塞类 | 必须点掉的告知，只有一个「知道了」 |
| P02 | Toast | 轻提示 | 轻提示类 | 自动消失、不可交互、错过了也没事 |
| P03 | Modal | 模态框 | 阻塞类 | 遮罩小房间，在里面做完一件事再走 |
| P04 | Drawer | 抽屉 | 面板类 | 从边缘滑出的面板，装导航或一批内容 |
| P05 | Popconfirm | 气泡确认框 | 锚定类 | 贴着按钮的小气泡，就地二次确认 |
| P06 | Tooltip | 文字提示 | 锚定类 | 长按/hover 出现的纯文字注解 |
| P07 | Snackbar | 条幅提示 | 轻提示类 | 底部条幅，可带一个「撤销」 |
| P08 | Notification | 系统通知 | 轻提示类 | 应用之外的系统级提示，门槛最高 |
| P09 | Popover | 气泡卡片 | 锚定类 | 锚定的富内容气泡，能干活 |
| P10 | BottomSheet / ActionSheet | 底部面板 / 动作面板 | 面板类 | 底部升起，两档高度，移动端首选 |
| P11 | Loading / Progress | 加载与进度 | 状态类 | 三档强度：非阻塞 / 按钮内 / 全局遮罩 |
| P12 | Badge / Dot | 角标与红点 | 状态类 | 附着在图标上的持续状态 |

**强度排序（选型时从上往下问）**：Alert > Modal > Drawer / BottomSheet >
Popconfirm / Popover > Snackbar > Toast；Loading 是过程反馈、Badge 是持续状态，
两者不「弹」但同属提示族。

**选型四问**：要不要打断？打断完要不要用户做事？事情发生在哪个元素旁边？错过这条信息会不会有损失？

## 3. 每条演示用到的真实 API（照抄时别换成假的）

| 条目 | 真实实现 | 关键点 |
|---|---|---|
| P01 | `AlertDialog`（只给 `confirmButton`）+ `DialogProperties(dismissOnBackPress/ClickOutside)` | 「不可绕过 / 可绕过」两态可切，验证 Alert 语义 |
| P02 | `Toast.makeText(context, …).show()` + 自绘轻提示（`LaunchedEffect` + `delay(2200)`） | 系统 Toast 与可定制轻提示并存，说明各自限制 |
| P03 | `androidx.compose.ui.window.Dialog` + `DialogProperties` + `OutlinedTextField` | 主按钮在空输入时禁用；点外面能否关可切 |
| P04 | `Box` + `animateFloatAsState` + `Modifier.offset { IntOffset(…) }` + scrim + `BackHandler` | 遮罩透明度与面板位移共用同一 `progress` |
| P05 | `DropdownMenu`（自动锚定 + 边缘翻转）承载「问话 + 取消/删除」 | 删除后给撤销，恢复到**原下标** |
| P06 | `combinedClickable(onLongClick = …)` + `DropdownMenu` + `LaunchedEffect` 自动消失 | 移动端没有 hover，长按等价；图标仍设 `contentDescription` |
| P07 | `SnackbarHostState` + `showSnackbar(msg, actionLabel = "撤销")` + `SnackbarResult.ActionPerformed` | `showSnackbar` 是挂起函数，撤销逻辑在其返回后判断 |
| P08 | `NotificationChannel` + `Notification.Builder(context, channelId)` + `NotificationManager.notify` + `POST_NOTIFICATIONS` 运行时申请 | 未授权时按钮禁用并说明，不静默失败；另给应用内预览便于核对文案 |
| P09 | `DropdownMenu` 内放自定义 `Column`（图标 + 标题 + 副标题 + 分隔线 + 开关行） | 证明 Popover ≠ 菜单项列表；行热区 ≥44dp |
| P10 | `ModalBottomSheet` + `rememberModalBottomSheetState(skipPartiallyExpanded = false)` + `sheetState.hide()` | 需 `@OptIn(ExperimentalMaterial3Api::class)`；关闭走 `hide()` 才有下滑动画 |
| P11 | `LinearProgressIndicator(progress = { p })` / 按钮内 `CircularProgressIndicator(16.dp, strokeWidth = 2.dp)` / 全局 `Box` 遮罩 + 取消 | 三档强度可切换对比；按钮加载态宽度不变 |
| P12 | `Box` + `Surface(RoundedCornerShape(percent = 50))` 自绘角标 + `CircleShape` 红点 | `count > 99 → 99+`；`count == 0` 整个角标不渲染 |

## 4. 接线（接到你的项目）

1. 复制 `features/overlayterms/` 两个文件到宿主同包路径（只改 `package`）。
2. 目录/详情页依赖仓库内 `GlassCard`、`SectionTitle`、`AppIcons`；宿主没有就换成
   `Surface` / `Text` / 你自己的图标，**不要改术语数据与演示逻辑**。
3. P08 用到 `R.drawable.ic_stat_launcher`（纯色通知小图标）；换成你自己的图标资源，
   并在 Manifest 声明 `POST_NOTIFICATIONS`（Android 13+ 必须运行时申请）。
4. 入口：`OverlayTermsCatalogSection(onOpen = { selectedId = it.id })`，
   详情 `OverlayTermsDetailScreen(term, onBack)`；选中态存 **id 字符串**（可保存），
   列表状态用 `rememberSaveable(saver = LazyListState.Saver)`，返回才不回顶部。

## 6. 验收清单

- [ ] 素材库第四分区显示「弹窗提示术语 · 12」，12 张卡片可点进详情，搜索与 5 个分类筛选计数正确（全部 12）。
- [ ] P01：不可绕过时点遮罩/返回键关不掉；可绕过时能关；确认次数累加。
- [ ] P02：系统 Toast 真的弹出；自绘轻提示 2.2s 自动消失；连点不叠一堆。
- [ ] P03：空输入时「保存」禁用；点外面能否关随开关变化；保存后名称回显。
- [ ] P04：抽屉滑入滑出，遮罩透明度与位移同步；点遮罩与返回键都能关；选中项回显。
- [ ] P05：气泡锚在按钮旁；删除后条目消失且「撤销」能把它放回**原位置**。
- [ ] P06：长按图标出提示，1.8s 自动消失；三个图标不互相串。
- [ ] P07：删除后底部出现条幅，点「撤销」条目回到原下标；不点则自动消失。
- [ ] P08：未授权时发送按钮禁用并给申请入口；授权后点发送能在通知栏看到；应用内预览与真实通知文案一致。
- [ ] P09：气泡内含菜单项与开关行，点外部/返回键关闭，选择后回显。
- [ ] P10：底部面板可拖拽、可半展开；选动作与取消都能关；关闭有下滑动画。
- [ ] P11：三档切换各自表现正确；全局遮罩期间背景不可点且能取消；按钮加载态宽度不跳。
- [ ] P12：`0` 不渲染角标、`99` 显示 99、`100` 显示 `99+`；红点可单独开关。
- [ ] 每条详情页提示词可点按展开、长按复制并有触感反馈；从详情返回列表停在原处。

## 7. 红线

1. 演示必须真实可操作：真 Toast / 真 AlertDialog / 真 DropdownMenu / 真 SnackbarHost /
   真 NotificationManager / 真 ModalBottomSheet。**不许用截图、静态卡片或 `Text("这里是弹窗")` 冒充**。
2. 术语定义改词要同步改 `strings.xml`（`ot_p*_definition` 等）与本文件，两处口径必须一致；条目骨架才在 `OverlayTermsSpec.kt`。
3. P01–P06 标注为视频简介点名的术语，P07–P12 标注为本仓库补足；**不许把补足的 6 条说成视频原话**。
4. 引用必须保留出处（UP 名 + 标题 + BV 号）。
5. 宿主接入时把某个术语换成「相似效果」的自创实现后，仍要按本模块的名字交付，
   就必须写明差异（与 `AGENTS.md` 红线 2 一致）。
