# 实现方式及方案

## 功能概述

允许用户在"设置 → 主题与外观"页面切换桌面应用图标，提供"经典图标"和"新图标"两种选项。切换立即生效（Android 12+），部分设备需回到桌面或重启启动器后刷新。

## 技术方案

### 1. 核心机制：activity-alias

Android 原生不提供直接修改应用图标的方法（Android 13 的 `setApplicationIcon` 是 `@RestrictedTo(System)` 内部 API，第三方应用无法调用）。业界标准方案是使用 `<activity-alias>`：

```
<activity  android:name=".MainActivity"
           android:icon="@drawable/icon"     android:enabled="true" />
<activity-alias android:name=".MainActivityIcon2"
                android:icon="@drawable/icon2" android:enabled="false"
                android:targetActivity=".MainActivity" />
```

**关键点：**

- `MainActivity`（真实 Activity）和 `MainActivityIcon2`（别名）指向同一个 `MainActivity`；
- 两者均声明 `<action android:name="android.intent.action.MAIN" />` + `<category android:name="android.intent.category.LAUNCHER" />`，因此都会出现在桌面；
- 通过 `PackageManager.setComponentEnabledSetting()` 交替启用一个、禁用另一个，系统自动更新桌面图标；
- 使用 `PackageManager.DONT_KILL_APP` 标志，避免切换时杀掉主进程。

### 2. 切换流程

```
用户点击"经典图标"或"新图标"
    │
    ▼
PackageManager.setComponentEnabledSetting(alias, ENABLED/DISABLED, DONT_KILL_APP)
PackageManager.setComponentEnabledSetting(main,  DISABLED/ENABLED, DONT_KILL_APP)
    │
    ▼
SettingsRepository.appIconVariant = variant   // 持久化
    │
    ▼
Android 桌面刷新（部分设备立即生效，部分需手动回到桌面或重启启动器）
```

### 3. 持久化

变体值（`0` = 经典图标，`1` = 新图标）存入 `SharedPreferences`（键名 `app_icon_variant`）：

- 下次冷启动时从 `SettingsRepository` 读取，恢复到上次选择的图标；
- 取值范围 `0..1`，写入时 `coerceIn(0, 1)` 保护。

### 4. 资源准备

每套图标需要以下资源文件：

| 资源 | 说明 |
|------|------|
| `res/drawable/icon.png` | 经典图标（launcher icon 前景） |
| `res/drawable/icon2.png` | 新图标（launcher icon 前景） |
| `res/drawable/ic_launcher_background.xml` | 自适应图标背景层（可选） |
| `res/mipmap-anydpi-v26/ic_launcher.xml` | 经典图标自适应 XML（引用 `@drawable/icon` 前景） |
| `res/mipmap-anydpi-v26/ic_launcher2.xml` | 新图标自适应 XML（引用 `@drawable/icon2` 前景） |

两种图标均通过 `<adaptive-icon>` XML 声明前景和背景层，适配 Android 8.0+ 自适应图标规范。

### 5. 局限性说明

| 平台 | 行为 |
|------|------|
| Android 12+ | 大多数启动器立即刷新图标 |
| Android 8-11 | 需要手动回到桌面或重启启动器（如 Nova / Lawnchair） |
| 部分 OEM ROM（小米 / 华为 / OPPO） | 系统级启动器缓存较深，可能需要清除桌面缓存或重启手机 |
| 应用首次安装 | 若系统同时解析两个 alias，可能初始显示两枚图标（属于正常行为，用户手动选择一个后会自动消失另一个） |

**重要：此方案无法做到无限数量的自定义图标切换**。如果需要更多图标变体，每增加一个变体都需要在 `AndroidManifest.xml` 中新增一个 `<activity-alias>` 条目，并为该变体准备独立的图标资源。建议变体数量控制在 2-4 个以内。

### 6. 与主题色配置的协同

`ThemeScreen.kt` 中桌面图标切换卡片与主题色卡片并列，均采用相同的可折叠展开动画模式（`Animatable` + `onSizeChanged` + `graphicsLayer`），保证 UI 风格统一。
