# 玻璃常用组件 · 环境要求

## 前置素材（需一并拷入）

| 素材 | 来源 | 说明 |
|---|---|---|
| 液态玻璃主题 | `素材库/液态玻璃主题/` | 提供 `liquidGlass`、`GlassCard`、`LocalAppChrome`、`AppShape` |
| 动效系统 | `素材库/动效系统/` | 提供 `pressScale`、`Motion` token |
| 底部导航栏（可选） | `素材库/底部导航栏/` | 若组件页需要 tab 演示 |

## 版本要求

| 项 | 要求 |
|---|---|
| compileSdk | 36（backdrop 依赖） |
| minSdk | 26 |
| Compose BOM | 2024.10.01（示例） |
| 玻璃降级 | `VisualMode.Normal/Md3` 时组件自动用实心 Material |

## 需要的文件

| 文件 | 说明 |
|---|---|
| `代码/Controls.kt` | 按钮 / 可拖开关 / 分段控件 / HSV 取色盘 |
| `代码/Dialogs.kt` | 真玻璃弹窗（`GlassDialogHost` 同窗浮层） |
| `代码/Feedback.kt` | `InfoBanner` / `Toast` 提示 |
| `代码/Rows.kt` | `SectionTitle` / `PreferenceRow` / `PreferenceCard` / 标题排版 |
| `代码/TextFields.kt` | 玻璃输入框 |

## 接线要点

- 弹窗必须通过 `GlassDialogHost` 提升到 App 根渲染（同窗浮层），否则玻璃退化成 tint。
- 可拖开关 / 分段控件的容器走 `liquidGlass`，随三态自动降级，勿单独加开关。
