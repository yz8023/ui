# 玻璃常用组件 · 实现方案

> 功能点：把"玻璃 + 动效"组合成可直接使用的常用控件库——按钮 / 开关 /
> 分段控件 / 输入框 / 弹窗 / 提示 / 设置行等。

## 1. 组件清单

| 组件 | 文件 | 说明 |
|---|---|---|
| `PrimaryButton` / `SecondaryButton` | `Controls.kt` | 主/次按钮，按压压扁反馈（无 ripple） |
| `CompactSwitch` | `Controls.kt` | 开关：拇指可**水平拖动**，松手按阈值吸附，玻璃材质 |
| `SegmentedTabs` | `Controls.kt` | 分段选择器：支持整条拖动，随三态自动降级 |
| `ColorWheel` / `GradientBar` | `Controls.kt` | 圆形 HSV 取色盘 / 渐变条（自绘，零依赖） |
| `GlassCard` / `GlassPill` | `Glass.kt` | 玻璃卡片 / 胶囊徽章（见 液态玻璃主题） |
| `GlassDialog` | `Dialogs.kt` | 真玻璃弹窗：同窗浮层 + 弹簧缩放入场 |
| `LoadingState` / `ErrorState` / `SuccessBanner` / `OfflineBanner` | `Feedback.kt` | 加载、失败、成功、离线与骨架屏状态反馈 |
| `InfoBanner` / `StatTile` | `Feedback.kt` | 信息提示条 / 指标卡 |
| `TextField` 变体 | `TextFields.kt` | 玻璃输入框 |
| `SectionTitle` / `PreferenceRow` / `PreferenceCard` | `Rows.kt` | 设置页行 / 卡片骨架 |
| `DisplayTitle` / `SupportingText` | `Rows.kt` | 标题 / 副文案排版 |

## 2. 实现约定（请务必遵守）

1. **一律玻璃材质**：可交互容器用 `liquidGlass`（随 `VisualMode` 三态自动降级
   为实心 Material，无需逐控件加开关）。
2. **按压有反馈**：可点控件叠 `pressScale`（来自动效系统），不依赖 ripple。
3. **可拖开关**：`CompactSwitch` 与 `SegmentedTabs` 的拇指用
   `Animatable` + `detectHorizontalDragGestures` 实现拖动，松手按 0.5 阈值吸附。
4. **取色自绘**：`ColorWheel` 用 Canvas 绘制 HSV 色相环 + 饱和度径向，明度滑条
   独立，零第三方依赖。

## 3. 关键组件说明

### CompactSwitch（可拖拽开关）

```
轨道（玻璃材质，描边+阴影）
 └─ 拇指（Animatable.x，可拖动）
     · 拖动中实时跟随并屏蔽回弹
     · 松手按 x 位置 / 轨道宽 0.5 阈值 → 弹簧吸附 + 反写状态
```

实现要点：`detectHorizontalDragGestures` 期间 `Animatable.snapTo`，松手后
`animateTo(0f / 轨道宽)` 弹簧归位，同时回调状态变更。容器统一 `liquidGlass`，
玻璃模式即玻璃轨道，普通/MD3 模式实心轨道。

### GlassDialog（真玻璃弹窗）

普通 `Dialog` 是独立 Window，**无法跨窗口采样 backdrop**，玻璃会退化成 tint。
解决方案（`Dialogs.kt`）：

- `GlassDialogHost` 把浮层**提升到 App 根 Box 末尾**同窗渲染；
- 幕帘层录制为 scrim backdrop，与 aurora `rememberCombinedBackdrop`；
- 卡片采样 combined 层真折射，入场用弹簧缩放 + 淡入；
- 无 backdrop（普通布局）时降级为纯色幕帘 + Material 卡片。

### ColorWheel（HSV 取色盘）

```
圆形画布：
 · 色相 = 角度（绕环）
 · 饱和度 = 半径（中心低 → 边缘高）
 · 明度 = 右侧独立滑条
点击 / 拖动即取色，实时回写状态
```

## 4. 使用示例

```kotlin
// 设置行
PreferenceCard {
    PreferenceRow(
        icon = AppIcons.Settings,
        title = "开关",
        subtitle = "副文案",
        trailing = { CompactSwitch(checked, onCheckedChange) }
    )
}

// 分段选择
SegmentedTabs(
    labels = listOf("玻璃", "普通", "MD3"),
    selectedIndex = current,
    onSelected = { index -> ... },
    modifier = Modifier.fillMaxWidth()
)

// 玻璃弹窗
GlassDialog(onDismissRequest, title = "标题", onConfirm = { ... }) {
    Text("弹窗内容，真玻璃折射背后页面")
}
```

## 5. 常见问题

| 问题 | 原因 / 处理 |
|---|---|
| 开关拇指顶到上边 | 拇指容器需 `contentAlignment = CenterStart` 竖直居中 |
| 拖开关没吸附 | 拖动与回弹的 `Animatable` 状态冲突，拖动中 `snapTo`、松手 `animateTo` |
| 弹窗是实心的 | 弹窗必须走 `GlassDialogHost` 同窗浮层，不能用系统 `Dialog` |
| 按钮没按压反馈 | 组件依赖动效系统的 `pressScale`，确认已拷入 |
