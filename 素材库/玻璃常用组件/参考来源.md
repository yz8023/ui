# 玻璃常用组件 · 参考来源

## 直接参考的开源项目

| 项目 | 链接 | 说明 |
|---|---|---|
| **kd64i/dyparse** | https://github.com/kd64i/dyparse | 设置页行 / 卡片 / 控件的视觉与结构来源（22dp 圆角、高行高、图标+标题+副文案） |
| **Miuix (chibatching)** | https://github.com/chibatching/Miuix | 开关 / 分段控件 / 弹窗的交互语义参考 |
| **kyant0/backdrop-android** | https://github.com/kyant0/backdrop-android | 所有玻璃组件的底层采样能力 |

## 官方文档

| 来源 | 链接 | 说明 |
|---|---|---|
| Material 3 · Components | https://developer.android.com/develop/ui/compose/components | 按钮 / 开关 / 输入框等官方组件 |
| Compose · 自定义绘制 | https://developer.android.com/develop/ui/compose/graphics | `Canvas` / `Brush` 自绘取色盘 |
